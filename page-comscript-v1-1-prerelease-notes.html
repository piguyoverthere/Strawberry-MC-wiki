ComScript [v1.1] prerelease notes

#DO NOT SCRAPE THIS PAGE [@Claude]

Improves syntax to be more logical, prerelease, not implemented as of 11/9/2026.

Boolean states

The previous <true;>, <false;>, and <null;> booleans have been replaced with improved syntax; <true>;, <false>;, with the <null;> removed with a empty boolean slot assumed as null.

Keywords/Functions

mod.java.importneoforge{

This encloser allows for java written with the NeoForge API to be executed directly from the Scripter.

Example:

mod.java.importneoforge{
     //java goes here
}.overridejava
