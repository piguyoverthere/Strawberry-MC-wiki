Comments

Comments in ComScript can be used to label different sections of code for better readability. Single-line comments can be initiated in or within any line at any bracket depth:

//this is a single-line comment
void function() { //this is a legal comment
}
void //this is a illegal comment function() {
}

Even though single-line comments can be placed at any bracket depth, they must be at the end of a line or the rest of the line also becomes a comment.

Multi-line comments can span for multiple lines, and are started and terminated by a quotation.

//"This is a multi-
line comment"

Multi-line comments can also be used inbetween a script:

void //"this is a legal multi-line comment"function() {
}

But take note of the spaces, as the comment as a space before it but not after, because since comments are completely skipped while compiling ComScript, the line would be read as having two spaces, which is illegal (see purpose and basics).
