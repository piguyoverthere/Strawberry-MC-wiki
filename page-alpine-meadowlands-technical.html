Alpine Meadowlands [technical]

Overview

Alpine Meadowlands is the biome strawberrymc:alpine_meadow, named "Alpine Meadow" in the language file. It is an MCreator biome element with two additions in hand-written code: a climate claim in SurfaceBiomeDepthMixin and a runtime temperature override in SetTemperatureBiomeModifier.

Surface rule

StrawberrymcModBiomes.preliminarySurfaceRule gives the biome minecraft:grass_block at the surface where the water check passes, gravel at the surface underwater, and minecraft:dirt at the deeper stone-depth check. The rule applies above the preliminary surface.

Runtime temperature override

A biome below 0.15 receives snow layers and snowfall. To keep the file's value of 0.1 from causing snow without editing MCreator's generated biome, the mod registers a custom biome modifier type, strawberrymc:set_temperature. The file biome_modifier/alpine_meadow_no_snow.json applies it with temperature 0.5.

@Override
public void modify(Holder<Biome> biome, Phase phase, ModifiableBiomeInfo.BiomeInfo.Builder builder) {
	if (phase == Phase.MODIFY && this.biomes.contains(biome))
		builder.getClimateSettings().setTemperature(this.temperature);
}
when modifying biomes:
    if this is the modify phase and the biome is one of this modifier's biomes:
        set the biome's temperature to this modifier's temperature

The record SetTemperatureBiomeModifier takes a biome holder set and a float through its MapCodec.

Climate

StrawberrymcModBiomes.modifyOverworldParameterPoints adds two points, one at depth 0 and one at depth 1.

ParameterRange
temperature-0.5 to 0
humidity-0.5 to 0.5
continentalness0.5 to 1
erosion-0.6 to 0
depthPoints 0 and 1
weirdness0.5 to 1
offset0

The climate generation temperature above is separate from the biome's own temperature value: the first decides where the biome appears, and the second controls effects such as snow.

The biome is in the SURFACE_BIOMES list of SurfaceBiomeDepthMixin. Vanilla covers every climate value, so a custom biome would otherwise only tie with a vanilla one and win at random. The mixin splits every other surface biome's climate box around the Alpine box, making it the only choice inside its ranges. Cave biomes, which use other depths, are left in place.

Each chunk makes one attempt at a random surface position. FirTree.place takes the block below the origin and continues only if it is in BlockTags.SUBSTRATE_OVERWORLD. The tree itself is described on Fir, and the choice of tree is made by DetermineRandFirProcedure [raw].

// substrate_overworld covers grass, dirt, podzol, moss and mud (DIRT alone no longer includes grass)
if (!level.getBlockState(ground).is(BlockTags.SUBSTRATE_OVERWORLD)) {
    return false;
}

DetermineRandFirProcedure.execute(level, ground.getX(), ground.getY(), ground.getZ());
return true;
if the ground block is not overworld ground (grass, dirt, podzol, moss or mud):
