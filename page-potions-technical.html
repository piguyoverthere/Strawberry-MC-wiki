Potions [technical]

The mod's potion content is made of one custom potion (strawberrymc:herb), two brewing recipes that form a chain from Thick Potion to the vanilla Potion of Luck, and one custom mob effect (strawberrymc:invulnerability). See the main Potions page and Clovers [technical] for the ingredient.

Potion of Herb

Potions are registered in init/StrawberrymcModPotions.java through a DeferredRegister<Potion> on Registries.POTION. StrawberrymcMod attaches that register to the mod event bus in its constructor. Herb is the only entry:

public static final DeferredHolder<Potion, Potion> HERB = REGISTRY.register("herb", () -> new Potion("herb"));

The constructor receives no MobEffectInstance arguments, so the potion applies nothing when drunk; its only purpose is to be a recipe step. The element file elements/Herb.mod.json records this as "effects": []. The display names come from four keys in assets/strawberrymc/lang/en_us.json, which are placed in the minecraft item namespace because the bottle items are the vanilla ones:

Recipe class structure

Both recipes live in recipe/brewing/ and use the same layout. Each class is annotated @EventBusSubscriber, implements NeoForge's IBrewingRecipe, and adds an instance of itself in a static RegisterBrewingRecipesEvent listener, so no central recipe list exists. isInput accepts drinkable, splash and lingering bottles and then compares the bottle's DataComponents.POTION_CONTENTS component against the required potion:

@Override
public boolean isInput(ItemStack input) {
	Item inputItem = input.getItem();
	return (inputItem == Items.POTION || inputItem == Items.SPLASH_POTION || inputItem == Items.LINGERING_POTION) && input.getOrDefault(DataComponents.POTION_CONTENTS, PotionContents.EMPTY).is(Potions.THICK);
}

@Override
public ItemStack getOutput(ItemStack input, ItemStack ingredient) {
	if (isInput(input) && isIngredient(ingredient)) {
		return PotionContents.createItemStack(input.getItem(), StrawberrymcModPotions.HERB);
	}
	return ItemStack.EMPTY;
}

Because getOutput passes input.getItem() to PotionContents.createItemStack, the bottle form carries through the brew: a Splash Thick Potion becomes a Splash Potion of Herb, and a Lingering Potion of Herb becomes a Lingering Potion of Luck. isIngredient is a plain Ingredient.of(...).test(ingredient) check against the single ingredient item.

Ingredient source

Rare Clover Cluff is produced by the block loot table data/strawberrymc/loot_table/blocks/clover_mat.json. The table has three independent one-roll pools. The third pool holds the single entry below, guarded by an inverted Silk Touch match_tool condition, so breaking a Clover Mat without Silk Touch gives a count between 0 and 1:

"name": "strawberrymc:rare_clover_cluff",
"weight": 1,
"functions": [
  {
    "function": "minecraft:set_count",
    "count": { "min": 0, "max": 1 }
  }
]

Obtaining the item triggers the advancement data/strawberrymc/advancement/luck_based.json (title key advancements.luck_based.title, "Luck Based"), which uses a minecraft:inventory_changed trigger on the item and rewards 2 experience.

Invulnerability effect

The mod's single mob effect is registered in init/StrawberrymcModMobEffects.java as strawberrymc:invulnerability and implemented by potion/InvulnerabilityMobEffect.java (element elements/Invulnerability.mod.json). It is named "Invulnerability" by the lang key effect.strawberrymc.invulnerability.

The effect class itself carries no ticking logic. Its protection comes entirely from the separate event handler below.

Immunity to other effects

InvulnerabilityEffectHandler subscribes to MobEffectEvent.Applicable, which fires when an effect is about to be added. While the entity has Invulnerability, every incoming effect other than Invulnerability itself is rejected with DO_NOT_APPLY:

if (entity.hasEffect(StrawberrymcModMobEffects.INVULNERABILITY)) {
    if (!event.getEffectInstance().getEffect().equals(StrawberrymcModMobEffects.INVULNERABILITY)) {
        event.setResult(MobEffectEvent.Applicable.Result.DO_NOT_APPLY);
        long currentTime = entity.level().getGameTime();
        long lastTime = COOLDOWN_MAP.getOrDefault(entity, 0L);
        if (currentTime - lastTime >= 10) {
            COOLDOWN_MAP.put(entity, currentTime);
            entity.playSound(SoundEvents.SHIELD_BLOCK.value(), 1.0F, 1.0F);

The block itself is unconditional, while the feedback is throttled. The per-entity last-trigger tick is held in a static WeakHashMap<LivingEntity, Long> named COOLDOWN_MAP, so entries are released once an entity is no longer referenced, and a deflection only plays feedback if at least 10 game ticks have passed. The feedback is the SHIELD_BLOCK sound at volume 1 and pitch 1, plus a server-side particle burst at the entity's vertical center:

Honey Bottle cure

InvulnerabilityMobEffect also subscribes to ModifyDefaultComponentsEvent. It copies the on-consume effect list of Consumables.HONEY_BOTTLE, appends a RemoveStatusEffectsConsumeEffect for Invulnerability, builds a new Consumable with the original consume time, animation, sound and particle flag, and sets it as the DataComponents.CONSUMABLE default on Items.HONEY_BOTTLE. Drinking honey therefore removes Invulnerability alongside honey's existing effects. The element flag for this is "isCuredbyHoney": true.

Invulnerability particle

strawberrymc:invulnerability_particle is a SimpleParticleType whose sprite is listed in assets/strawberrymc/particles/invulnerability_particle.json. The renderer is client/particle/InvulnerabilityParticleParticle.java, registered in init/StrawberrymcModParticles.java. It has a 0.2 by 0.2 size, a lifetime of 35 ticks, a gravity of -1.7f that makes it rise, no block collision (hasPhysics = false) and the OPAQUE render layer.

Effect source in code

The only code outside the effect's own files that uses the effect is block/EchowoodSaplingBlock.java. It extends FlowerBlock and passes the effect to the super constructor as its suspicious stew effect, with a duration argument of 100. The element elements/EchowoodSapling.mod.json stores the same pair as suspiciousStewEffect and suspiciousStewDuration.
