Lobby: Settings

The Lobby is a new structure that the player will spawn in if lobby is configured to true, containing portals that will change the game mode and settings of the world. Once the player spawns in, they will be in Adventure mode and will be able to enter colored nether portals. 5 portals are present, Parabola mode, Realism mode, Creative mode, Maps, and Gameplay. These 5 portals once entered, will teleport the player to their corresponding pick and set their game mode to the default game mode. For the Gameplay portal, a set of 3 sub portals will appear once entered. The 3 portals allow the player to select their game mode and other settings such as methods of beating the game including Aadi’s method, Classic, Eric’s method, Sai’s method, and hardcore.[more to come]


Note that once the player completes configuration in the lobby, the player can no longer enter the lobby unless they use /lobby [operator only]
