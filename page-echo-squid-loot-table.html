Echo Squid Loot Table

If killed with item (affected and weighted by looting):

Shrieking Gladius 0.75 1-2x Chorus Fruit 0.15 1-3x

If killed with melee weapon enchanted with Fire Aspect >0 overriding previous loot table statements:

Shrieking Gladius 0.75 1-2x Popped Chorus Fruit 0.15 1-2x

The echo squid when killed will drop 1-2 echo squid gladius. These gladiuses can be used [see also: locater compass]* to make a vial of shrieking or to make the locater compass.
