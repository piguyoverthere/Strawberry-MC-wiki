Voidstone [technical]

Block class

Voidstone is strawberrymc:voidstone, registered in StrawberrymcModBlocks as VoidstoneBlock. All of its behavior is set in the constructor's property chain, plus one override that lets plants grow on it.

public VoidstoneBlock(BlockBehaviour.Properties properties) {
	super(properties.mapColor(MapColor.TERRACOTTA_BLACK).sound(SoundType.BONE_BLOCK).strength(7f).requiresCorrectToolForDrops().friction(0.4f).speedFactor(0.9f).instrument(NoteBlockInstrument.BASEDRUM));
}

@Override
public TriState canSustainPlant(BlockState state, BlockGetter world, BlockPos pos, Direction direction, BlockState plant) {
	return TriState.TRUE;
}

Use in world generation

Voidstone is the matrix of The Void. It enters the terrain in three places:

  • default_block in noise_settings/void_dim.json. Every position with positive final density becomes Voidstone, so the plain, mountains, islands, pillars and bridges are all made of it.
  • The surface rule in the same file, which places Voidstone at floor depth in Voidstone Peaks, Abyssal Plains and Echoing Deep.
  • The barrier state of the void_tears_pool configured feature, which lines Void Tears pools.

The biome JSON files list the minecraft:cave, minecraft:cave_extra_underground and minecraft:canyon carvers, and the carver tag above is what lets them open caves in it.
