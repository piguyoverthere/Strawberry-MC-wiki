Log Output

Other than outputing text in chat, you can also manipulate the native ComScript log found in the Scripter. As in some cases, you might want to send debug messages in the native ComScript log. In ComScript, the console superclass extends all actions regarding in native log.

Example:

console.log("Log text");
#expected output:#
\level\comscript\log.md {
    [11-18-2026-2.54.32] \comscript > Log text
}

ComScript also allows for yellow warn messages and red error messages, which are also used for debugging or log reading scripts.

Warn Example:

console.warn("Warning");
#expected output:#
\level\comscript\log.md {
    [11-18-2026-2.54.32] \comscript > Log text
}

Error example:

console.alert("Error");
#expected output:#
\level\comscript\log.md {
    [11-18-2026-2.54.32] \comscript > Error
}

ComScript also allows for variable embedding into log outputs, which outputs the value of the variable in the script during the exact moment the console superclass is detected.

Example:

store new myVar = "hello";
console.log("Value of variable myVar is ", $myVar);
#expected output:#
\level\comscript\log.md {
    [11-18-2026-2.54.32] \comscript > Value of variable myVar is hello
}

Console logs support all valid unicode characters.
