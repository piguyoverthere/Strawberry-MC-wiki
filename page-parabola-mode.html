Parabola Mode

Parabola Mode is a gamemode that can be either switched into by using /difficulty parabola or by selecting the Parabola difficulty when creating a world using the Lobby [read also: Lobby]. Parabola Mode is a compilation of April fools features with funky mechanics that are supposed to confuse the player. Parabola Mode is best used with survival mode or using Parabola Mode features for escape rooms.
