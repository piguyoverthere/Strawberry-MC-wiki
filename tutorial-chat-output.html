Chat Output

ComScript can append messages in chat as the user "[\comscript]". Chat messages can be appended as either client or server. Server chat messages are visible to everyone, while client messages are only visible to yourself. The following example sends a server wide chat message:

server.chat.out("Hello World");

or a client side chat message:

client.chat.out("Hello Myself");

Settings of chat messages can be modified with CSON, including color, font, style, or size. The following example sends a yellow, sans-serif, bolded, large message:

server.chat.out("Cool text") {
    .color(rgb(100, 100, 0));
    .fontFamily("sans-serif");
    .strawberrymc.styles{
        "bold":<true;>
        "italic":<true;>
    }

Other methods

Styles with the Minecraft native section syntax can also be used:

server.chat.out("Green text") {
    .server.getStyleStack(){
        "§a"
    }
}
See formatting codes

If multiple formatting codes contradict, such as a formatting code for green and for red are provided, the last formatting code takes ownership. For example, the following only applies §a instead of §0:

server.chat.out("Text is still green") {
    .server.getStyleStack() {
        "§a",
        "§0" // Style 0 (black) takes priority
    }
}

You can also use the JSON styling format that is used in /tellraw messages:

server.chat.out(tellraw.getText()) {
    .server.getTellraw() {
        "text": "Hello, world!",
        "color": "green"
    }
}

In the code above, tellraw.getText() must be used as the input, or the style components in the .server.getTellraw() will not be used. .server.getTellraw() must have a "text" property to output anything.

A .server.getTellraw() must be nested within the chat output statement or tellraw.getText() will error syntax error.

Compatible components

Any compatible component is a property allowed to be nested within the chat output wrapper.

.color(<color format>, <opt: starting index>, <opt: ending index>);

The color property determines the color of a text with no limit for each chat output wrapper. Each color property has 2 possible input slots, the first one for color (supports either RGB or HEX code) and a 2 index integers, which tell ComScript which part of the text to color (including spaces). Since the index is optional, if no index is given, ComScript just assumes the entire text.

.fontFamily(<font name>, <opt: starting index>, <opt: ending index>);

The font family property species the font of the text with either external fonts that are pre-installed (such as Mojangles) or fonts that StrawberryMC provides. Similar to the color property, a starting and ending integer index specifies the area the font should be applied to, and assumes the entire text string if not specified.

.strawberrymc.size(<size in points>, <opt:starting index>, <opt:ending index>);

The size property changes the size of the text in points from the default. The default text size is 12 points. Similar to the components above, the index specifies the area to apply the text size modifiier to.

.strawberrymc.styles{ };

The styles property applies different text styles such as bold, italic, underline, strikethrough, and more. Style properties are invoked via the format "<style name>":<boolean> and must be comma seperated. Legal styles include:

StyleCall syntax
Bold"bold":<true;>
Obfuscated"obfuscated":<true;>
Italic"italic":<true;>
Underlined"underline":<true;>
Strikethrough"strikethrough":<true;>
Reset all styles"reset":<true;>

Example for bold, italic, underlined text:

server.chat.out("Styled text") {
    .strawberrymc.styles {
        "bold":<true;>
        "italic":<true;>
        "underline":<true;>
    }
}
