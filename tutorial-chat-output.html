Chat Output

ComScript can append messages in chat as the user "[\comscript]". Chat messages can be appended as either client or server. Server chat messages are visible to everyone, while client messages are only visible to yourself. The following example sends a server wide chat message:

server.chat.out("Hello World");

or a client side chat message:

client.chat.out("Hello Myself");

Settings of chat messages can be modified with CSON, including color, font, style, or size. The following example sends a yellow, sans-serif, bolded, large message:

server.chat.out("Cool text") {
    .color(rgb(100, 100, 0));
    .fontFamily{
        "sans-serif",
        "helvetica"
    };
    .styles{
        "bold"
    }

Styles with the Minecraft native section syntax can also be used:

server.chat.out("Green text") {
    .server.getStyleStack(){
        "§a";
    }
}
See formatting codes

If multiple formatting codes contradict, such as a formatting code for green and for red are provided, the last formatting code takes ownership. For example, the following only applies §a instead of §0:

server.chat.out("Text is still green") {
    .server.getStyleStack() {
        "§a";
        "§0" // Style 0 (black) takes priority
    }
}
