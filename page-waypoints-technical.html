Waypoints [technical]

The mod's Waypoints code is a seed-based location calculator. The Chiseled Cauldrons found inside Waypoints are covered on Chiseled Cauldrons [technical], and using a Smite Vial on one is covered on Spells For Chiseled Cauldrons [technical].

Location prediction

CalculateWaypointLocationProcedure [raw] is a Java class with one static method, predictRareVegetalLocation(long worldSeed, int chunkX, int chunkZ, int rarityChance). It predicts from the seed alone whether a rare feature will appear in a chunk, and at which x and z, without generating it. No other code calls the method.

WorldgenRandom random = new WorldgenRandom(new XoroshiroRandomSource(0L));
random.setDecorationSeed(worldSeed, chunkX << 4, chunkZ << 4);

long internalModifierSalt = random.nextLong();
WorldgenRandom filterRandom = new WorldgenRandom(new XoroshiroRandomSource(internalModifierSalt));

if (filterRandom.nextInt(rarityChance) != 0) {
    return new PredictionResult(false, BlockPos.ZERO);
}

int offsetX = random.nextInt(16);
int offsetZ = random.nextInt(16);
set up a world-gen random seeded from the world seed and this chunk's position (the decoration seed)
take the next random number as a salt and make a second filter random from it
if the filter random doesn't roll 0 out of rarityChance (a 1 in rarityChance chance):
    return no structure here
pick a random x offset and z offset from 0 to 15 within the chunk
  1. A WorldgenRandom over XoroshiroRandomSource receives the decoration seed for the chunk's block coordinates.
  2. One nextLong seeds a separate filter random, which rolls nextInt(rarityChance). Any result other than 0 means no feature.
  3. On a pass, the original random gives the x and z offsets within the chunk, and the block position is (chunkX << 4) + offsetX, (chunkZ << 4) + offsetZ.
  4. The y coordinate is a constant 64, since the terrain is not consulted.

The result is the record PredictionResult(boolean isPresentInChunk, BlockPos position).
