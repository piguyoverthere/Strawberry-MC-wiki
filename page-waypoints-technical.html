Waypoints [technical]

The mod's Waypoints code is the Chiseled Cauldron block, the Smite Vial interaction with it, and a seed-based location calculator.

Chiseled Cauldron

ChiseledCauldronBlock (strawberrymc:chiseled_cauldron) comes from elements/ChiseledCauldron.mod.json. It is listed in the Transportation, Operator and Debug creative tabs, and its loot table drops the block itself.

Shape

The voxel shape is a basin with a 5-pixel floor and 2-pixel walls:

private static final VoxelShape SHAPE = Shapes.or(box(0, 0, 0, 16, 5, 16), box(0, 5, 0, 16, 16, 2),
		box(0, 5, 14, 16, 16, 16), box(0, 5, 2, 2, 16, 14), box(14, 5, 2, 16, 16, 14));

getVisualShape returns Shapes.empty().

Particles

animateTick calls AmbientParticleEnchantProcedure [raw], which only sends particles when the world argument is a ServerLevel. animateTick runs on the client, so this branch is skipped.

Smite Vial on a Chiseled Cauldron

SmiteVialItem.useOn runs SmiteHandlerProcedure [raw] with the clicked position, the player and the item stack. The rest of the procedure only runs if the clicked block is a Chiseled Cauldron.

  1. The sound item.bucket.empty plays at the cauldron.
  2. For every entity other than the user in a box inflated by 5 blocks around the clicked position, sorted nearest first, a minecraft:lightning_bolt spawns at the entity and entity.arrow.hit_player plays.
  3. 36 ANGRY_VILLAGER particles spawn one block above the position, using cos(Angle) and sin(Angle) as the spread. Angle increases by 10 per particle.
  4. Outside creative mode, one vial is removed from the stack.

Location prediction

CalculateWaypointLocationProcedure [raw] is a Java class with one static method, predictRareVegetalLocation(long worldSeed, int chunkX, int chunkZ, int rarityChance). It predicts from the seed alone whether a rare feature will appear in a chunk, and at which x and z, without generating it. No other code calls the method.

WorldgenRandom random = new WorldgenRandom(new XoroshiroRandomSource(0L));
random.setDecorationSeed(worldSeed, chunkX << 4, chunkZ << 4);

long internalModifierSalt = random.nextLong();
WorldgenRandom filterRandom = new WorldgenRandom(new XoroshiroRandomSource(internalModifierSalt));

if (filterRandom.nextInt(rarityChance) != 0) {
    return new PredictionResult(false, BlockPos.ZERO);
}

int offsetX = random.nextInt(16);
int offsetZ = random.nextInt(16);
  1. A WorldgenRandom over XoroshiroRandomSource receives the decoration seed for the chunk's block coordinates.
  2. One nextLong seeds a separate filter random, which rolls nextInt(rarityChance). Any result other than 0 means no feature.
  3. On a pass, the original random gives the x and z offsets within the chunk, and the block position is (chunkX << 4) + offsetX, (chunkZ << 4) + offsetZ.
  4. The y coordinate is a constant 64, since the terrain is not consulted.

The result is the record PredictionResult(boolean isPresentInChunk, BlockPos position).
