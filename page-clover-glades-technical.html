Clover Glades [technical]

The Clover Glades are the biome strawberrymc:clover_glades, an MCreator element in elements/CloverGlades.mod.json. The plant blocks are described on Clovers [technical]; this page covers the biome and the features that place them.

Climate

StrawberrymcModBiomes.modifyOverworldParameterPoints appends two parameter points to the Overworld preset, identical except for depth. Generated code uses the depth points 0 and 1, the two values vanilla uses for surface biomes.

ParameterRange

The biome is not in the SURFACE_BIOMES list of SurfaceBiomeDepthMixin, so its climate boxes share space with the vanilla entries that already cover those values. The general pipeline is on Terrain Generation.

Clover patch feature

elements/CloverPatch.mod.json generates configured_feature/clover_patch.json, placed_feature/clover_patch.json and biome_modifier/clover_patch_biome_modifier.json. The modifier adds the placed feature to strawberrymc:clover_glades in the vegetal_decoration step, and that restriction is the only biome limit: the placed feature has no minecraft:biome filter of its own.

Configured feature

The configured feature is a minecraft:simple_random_selector holding one inline placed feature, the form MCreator's random patch block compiles to. That feature is minecraft:simple_block placing strawberrymc:clover_mat.

{ "type": "minecraft:count", "count": 96 },
{ "type": "minecraft:random_offset",
  "xz_spread": { "type": "minecraft:trapezoid", "plateau": 0, "min": -7, "max": 7 },
  "y_spread": { "type": "minecraft:trapezoid", "plateau": 0, "min": -3, "max": 3 } },
{ "type": "minecraft:block_predicate_filter",
  "predicate": { "type": "minecraft:all_of", "predicates": [
    { "type": "minecraft:matching_blocks", "blocks": "minecraft:air" },
    { "type": "minecraft:matching_blocks", "blocks": "#minecraft:dirt", "offset": [0, -1, 0] }
  ] } }

Each of the 15 to 35 patches makes 96 tries within 7 blocks horizontally and 3 vertically. A try succeeds only in air directly above a block in #minecraft:dirt.

The placed feature runs count 1, in_square, surface_water_depth_filter with a maximum depth of 0, heightmap OCEAN_FLOOR, biome, and a would_survive check against minecraft:oak_sapling, so each chunk gets one attempt on dry land.

Related procedures

  • CloverPlantProcedure [raw] places a clover_mat one block above the target position and removes one clover_cluff from the player.
  • CloverMatOnBoneMealSuccessProcedure [raw] subscribes to PlayerInteractEvent.RightClickBlock and, on a one-in-three roll, picks one of four horizontal directions and sets a clover mat on an air position there.
  • CloverMatPlacementReturnHandlerProcedure [raw] returns true when the block below the position is in minecraft:dirt.
