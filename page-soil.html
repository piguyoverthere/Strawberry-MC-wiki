Soil

Most to all generation of Dirt on the first 1-2 blocks under a grass block have been replaced to soil, with the same properties as Dirt, but darker in color. Dirt still naturally generates, [read but is far less abundant; only generating in small patches near exposed Stone features also: exposed Stone][read also: talus slopes] , talus slopes, rocky beaches, and below soil. The new layout for layers is: 1. Grass blocks (1 block thick) 2. Soil (1-3 blocks thick) 3. Dirt (1-2 blocks thick) 4. Gravel (1-2 blocks thick) 5. Exposed Stone (possible generation in some biomes; in which it is 1 block thick) 6. Stone (variable across terrain) 7. Deepslate (variable across terrain) 8. Bedrock (1-5 blocks thick)
