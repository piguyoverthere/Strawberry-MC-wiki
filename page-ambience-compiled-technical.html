Ambience (Compiled) [technical]

Overview

This page covers the code behind Ambience (Compiled). The mod ships two ambient sound events for the Void, and the audio settings of the dimension itself are defined in its dimension type JSON. The dimension is documented on The Void [technical].

Sound events

StrawberrymcModSounds registers the events in a DeferredRegister for Registries.SOUND_EVENT. StrawberrymcMod attaches that register to the mod event bus. Both are created with SoundEvent.createVariableRangeEvent.

public static final DeferredHolder<SoundEvent, SoundEvent> VOID_AMB_01 = REGISTRY.register("void_amb_01", () -> SoundEvent.createVariableRangeEvent(Identifier.fromNamespaceAndPath("strawberrymc", "void_amb_01")));
public static final DeferredHolder<SoundEvent, SoundEvent> VOID_AMB_02 = REGISTRY.register("void_amb_02", () -> SoundEvent.createVariableRangeEvent(Identifier.fromNamespaceAndPath("strawberrymc", "void_amb_02")));

Neither entry has a subtitle field, and the lang keys subtitles.void_amb_01 and subtitles.void_amb_02 are empty strings.

Playback

No Java class, biome file or dimension file references the two events. They play by ID through commands, for example /playsound strawberrymc:void_amb_01 ambient @s.

Void dimension music

data/strawberrymc/dimension_type/void_dim.json sets background music through the environment attribute minecraft:audio/background_music, using vanilla tracks.

Void Tears hiss

VoidTearHissProcedure [raw] plays block.lava.extinguish on SoundSource.AMBIENT at volume 1 and pitch 1. VoidTearsBlock.neighborChanged calls it whenever a neighboring block changes, so it is triggered by block updates next to Void Tears.
