Propogation

Inferno Lilies can be propagated in 2 ways:

Silk Touch > 0 tools can be used to harvest the tuber, which can be replanted on the following blocks:

  • Netherrack
  • Basalt
  • Crimson Nylium
  • Warped Nylium

Ash layers can be right-clicked, which gives a 0.3 chance of causing the tuber to spread to an adjacent valid block and duplicate itself.
