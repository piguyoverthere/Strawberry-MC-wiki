Crystal Hollows [technical]

Overview

Crystal Hollows is the cave biome strawberrymc:crystal_hollows. World generation runs in this order:

  1. The biome's surface rule lays Crystalline Calcite and calcite on cave floors.
  2. CrystalHollowsCarver hollows out one vast cavern and crusts every surface it opens.
  3. calcite_cleanup runs in the first feature step and clears any floating Crystalline Calcite.
  4. Decoration features fill the cavern with columns, mountains, geodes, pools and crystals.

The cavern is a carver instead of a feature so that every neighboring chunk is carved before any feature runs. The crystal columns, calcite mountains, geodes and pools are then never cut in half by a neighbor carving later.

Surface rule

StrawberrymcModBiomes.anySurfaceRule applies from 5 blocks above the world bottom to 5 blocks below the top. At floor depth it places Crystalline Calcite where the water check passes and calcite otherwise, and calcite below the floor at the deeper stone-depth check. It is added to the front of the overworld surface rule sequence.

CrystalHollowsCarver

Registration

The class extends WorldCarver<CarverConfiguration> and is registered as strawberrymc:crystal_hollows. The configured carver has probability 1.0 and uses #minecraft:overworld_carver_replaceables as its replaceable set. The biome modifier crystal_hollows_carver.json adds it to every biome, using neoforge:any. A chunk takes its carvers from its biome at y=0, which is often not Crystal Hollows, so the carver checks the biome at each block instead.

Order of work in carve()

  1. isStartChunk always returns true, and carve returns unless the source chunk is the chunk being generated, so each chunk carves only itself.
  2. It reads the biome straight from the chunk on the 4x4x4 biome grid, building a weight array of 1 for Hollows cells and 0 otherwise. It stops if no cell is Hollows.
  3. It builds a Shape, which samples the cave noise, column ceilings and pillar noise one block past the chunk edge, so surfaces on the border can see the neighbor's cavern before that chunk is carved.
  4. For each column from FLOOR up to the column's ceiling, every position where shape.open is true is set to plain air, if it is replaceable, lava, water or Crystalline Calcite. Plain air is used because MCreator's air predicate matches only minecraft:air.
  5. A second top-down pass applies the crust.

Noises

The noises are created once per RandomState from the random factory strawberrymc:crystal_hollows and kept in a weak map.

NoisefirstOctaveAmplitudesSampling
cave-71, 1, 0.5, 0.253D every 4 blocks, trilinearly interpolated, y multiplied by 1.8
pillars-51, 0.6, 0.32D, every block
wobble-31, 0.53D, every block

Stretching y by 1.8 makes chambers wide and flat instead of round.

Density formula

double t = (y - FLOOR) / (double) (ceiling - FLOOR);
double shell = Math.max(0, SHELL - t) / SHELL + Math.max(0, t - (1 - SHELL)) / SHELL;
double density = -0.35 - 0.9 * caveNoise(lx + CELL, y - FLOOR, lz + CELL) + 1.3 * shell * shell + 2.5 * (1 - w);
if (density >= 0)
	return false;
// Pillars flare out toward the floor and ceiling like they grew into the rock
double edge = 2 * t - 1;
return pillars[lx + 1][lz + 1] + 0.06 * noises.wobble.getValue(minX + lx, y, minZ + lz) <= 0.5 - 0.22 * edge * edge;
TermMeaning
tHeight within the column's cavern, 0 at the floor and 1 at the ceiling
shell0 through the middle 60%, rising to 1 at the floor and ceiling
-0.35Base bias toward open space
-0.9 * caveNoise that shapes the chambers
1.3 * shell²Closes the floor and ceiling smoothly
2.5 * (1 - w)Fills the cavern in at the biome's edge

A column's ceiling is min(36, ground - 12), where ground is found by scanning down for the top solid block, because the worldgen heightmaps are not filled in when carvers run. Fluids are skipped by the scan, so the cavern stays 12 blocks under a sea floor. A column with a ceiling at or below y=-42 stays solid.

The biome weight w is a trilinear blend of the 4x4x4 grid, so the cavern edge fades into rock instead of stepping in 4-block cubes. Positions with a weight at or below 0.05 are not carved.

Stone pillars

The final line of the formula keeps rock where pillars + 0.06 * wobble exceeds 0.5 - 0.22 * edge². The edge value is 0 at mid height and 1 at the floor and ceiling, so the threshold falls from 0.5 to 0.28 and the pillars flare where they meet the rock.

Crust

BlockState above = chunk.getBlockState(pos.above());
BlockState crust = null;
if (above.isAir())
	crust = crystalline;
else if (above.is(crystalline.getBlock()) || shape.air(lx, y - 1, lz) || shape.air(lx - 1, y, lz) || shape.air(lx + 1, y, lz)
		|| shape.air(lx, y, lz - 1) || shape.air(lx, y, lz + 1))
	crust = calcite;

The pass runs from one block above the ceiling down to y=-52. A replaceable block with air above becomes Crystalline Calcite. A block under Crystalline Calcite, or one with air beneath or beside it, becomes calcite. Running top-down means a floor block is already crystalline when the block under it is reached. Shape.air reads the chunk for positions inside it and calls open for positions in the neighboring chunk.

The Java features are registered in CrystalHollowsDecor. Its ProcedureFeature wrapper runs an MCreator procedure at the position the placed feature found.

calcite_cleanup

Vanilla cave carvers do not count Crystalline Calcite as carvable, so where they cut under a crusted floor the slab is left floating. CalciteCleanup runs once per chunk after all carving and removes any Crystalline Calcite with an empty block directly below it, from one block above the world bottom to the top of the world.

crystal_column

CrystalColumnGenerationProcedure [raw] builds a leaning triangular column from floor to ceiling.

  • Material: one of six equally likely blocks: minecraft:amethyst_block, garnet_block, dendrite_block, citrine_block, aquamarine_block or rose_quartz_block.
  • Gap: it counts air upward from the origin, and the column is built only when the height h is at least 8 and less than 120.
  • Lean: x and z each drift by a random amount from -5 to 5, divided by h + 3, per block of height.
  • Radius: an integer from 3 to 5. A random rotation from 0 to 2.0944 radians orients the triangle.
  • Range: layers run from 3 below the origin to h + 3, so both ends are embedded in rock.
  • Replaces air and minecraft:base_stone_overworld.
r = (radius * (1 + (0.5 * Math.pow(Math.min(Math.abs((((2 * i) / h) - 1)), 1), 4))));
reach = (Math.round(r) + 1);
cx = (x + (lean_x * i));
cz = (z + (lean_z * i));

The flare factor is 1 at mid height and 1.5 at the ends. A position belongs to the column when its offset, dotted with each of three unit normals 120 degrees apart, is at most r / 2.

calcite_mountain

CalciteMountainGenerationProcedure [raw] builds a mound. The radius is an integer from 7 to 13 and the height is from 0.8 to 1.6 times the radius.

top = Math.round(((height * Math.pow((1 - dist), 1.4)) + Mth.nextDouble(RandomSource.create(), -0.6, 1.2)));
if (top >= 0) {
	k = top;
	while ((k > -12) && (world.isEmptyBlock(BlockPos.containing((x + dx), (y + k), (z + dz))))) {
		world.setBlock(BlockPos.containing((x + dx), (y + k), (z + dz)), Blocks.CALCITE.defaultBlockState(), 3);
		k = (k - 1);
	}

Each column fills with calcite down through empty space, to at most 12 blocks below the origin, which skirts the mound over uneven floors. If the block above the top is empty it receives a Crystalline Calcite cap.

hollows_scattered_crystals

A simple_block with a weighted state provider of the six crystals at weight 1 each, facing up. It has its own placement: count 48, random offset with trapezoid spread from -7 to 7 horizontally and -3 to 3 vertically, then a filter requiring Crystalline Calcite with a solid block below.

Fog

CrystalHollowsFog is a client event subscriber on ViewportEvent.RenderFog. The cavern is open enough to see out to the edge of the loaded chunks, so inside the biome it closes the atmospheric fog in well before the render distance and fades the view into the biome's dark fog color.

FogData fog = event.getFogData();
fog.environmentalStart = Math.min(fog.environmentalStart, FOG_START);
fog.environmentalEnd = Math.min(fog.environmentalEnd, FOG_END);
fog.renderDistanceStart = Math.min(fog.renderDistanceStart, FOG_START);
fog.renderDistanceEnd = Math.min(fog.renderDistanceEnd, FOG_END);
// No sky or clouds show through gaps in the cavern; they're drawn in the fog colour
fog.skyEnd = 0;
fog.cloudEnd = 0;

FOG_START is 20 and FOG_END is 72.
