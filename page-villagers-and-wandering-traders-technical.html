Villagers And Wandering Traders [technical]

The mod adds villager trades through data files. All three custom offers involve Sulfur Slag (strawberrymc:sulfur_slag), the fertilizer used by Poor and Fertile Farmland [technical]. The Shocking enchantment is also registered for villager trading. See the main Villagers And Wandering Traders page.

Trade data

Each offer is a JSON file under data/strawberrymc/villager_trade/<profession>/<level>/, generated from an MCreator villagertrade element. No Java class is involved.

A file in this directory has the following shape, shown here with the hoe trade:

{
  "wants": { "id": "strawberrymc:sulfur_slag", "count": 4 },
  "additional_wants": { "id": "minecraft:emerald", "count": 2 },
  "gives": { "id": "minecraft:iron_hoe" },
  "max_uses": 5,
  "xp": 6,
  "reputation_discount": 0.05
}

A count of 1 is omitted from the JSON, which is why the melon seed trade writes its emerald as { "id": "minecraft:emerald" }. The villagerProfession and level fields determine the directory path and which tag receives the trade.

Trade tags

A trade file only joins a villager's pool when a vanilla-namespace tag lists it. The mod adds to two tags under data/minecraft/tags/villager_trade/. Both use "replace": false, so vanilla offers stay in the pool:

Tag fileValues
toolsmith/level_1.jsonstrawberrymc:toolsmith/1/sulfur_get_0
farmer/level_2.jsonstrawberrymc:farmer/2/sulfur_trade_farmer_melon_seed_0, strawberrymc:farmer/2/sulfur_trade_farmer_hoe_0
 
{
  "replace": false,
  "values": [
    "strawberrymc:farmer/2/sulfur_trade_farmer_melon_seed_0",
    "strawberrymc:farmer/2/sulfur_trade_farmer_hoe_0"
  ]
}

Enchantment trading

The Shocking enchantment (strawberrymc:electricution, element elements/Electricution.mod.json) has "canVillagerTrade": true in its element. In data, that setting appears as an entry in data/minecraft/tags/enchantment/tradeable.json, which uses "replace": false and lists strawberrymc:electricution.
