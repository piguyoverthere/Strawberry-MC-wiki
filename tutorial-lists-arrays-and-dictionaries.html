Lists, Arrays, and Dictionaries

Note the case sensitivity and legal character rules in Syntax: Variables still applies here.

Lists

Similar to variables, lists are a collection of values. These values can be any combination of data types, and all string items should be encased with quotations, integers and floats do not need quotations, selectors should start with "@" and variables should start with "$" [see Syntax: Variables: Fetching]. This can be overridden with the data type converters [see Purpose and Basics: Data types].

Creation

Lists can be created in the same way variables are created, by using the store keyword. Lists are differentiated from variables during creation by using curly brackets ({}).

Example:

store new myList = {};

Lists can also be created with items already inside:

store new myList = {"apple", 3, @r};

Similar to variables, lists can be fetched with $<list name>. Due to this, lists can not share names with variables, and if a list is created after a variable of the same name is created, then the program errors: unexpected data structure. When fetched, a list outputs in the format:

// Code:
store new myList = {"cheese", 4, <true;>};
client.chat.out($myList);

Expected client chat output:

[!]:cheese, 4, true

Modification, fetching, and indexing

Once a mutable list is created traits/contents of the list can be fetched and modified.

Append

Item(s) of any format can be appended to lists with the store <list name> append {<item 1>, <item 2>} format.

Example:

store myList append {"new item!"};

Multiple items can be appended at once using:

store myList append {"item 1", "item 2", 3};

Items can also be inserted at a certain index using:

store myList append.i(5|6) {"inserted item"};

Note

This code inserts the specified item in between item 5 and 6.

If items are inserted between two items that don't exist, then ComScript errors syntax error.

Void

Items can also be voided (deleted) from a list:

store myList void {.i(3), foot}
// This script voids item 3 and all occurences of "foot" within myList.

Note

All item indexes to void are always encased in [] and the list is stagnant until this script is finished, meaning that the values are not shifted forward to replace the null gap until all parts of the void are executed.


Fetch from item

Items from a list can be read from a list with the i (index) value:

store new item = mylist.i(3);
// The index is within the square brackets

Fetch length

The length of a list can be fetched with len():

store new myListLength = len(myList);
//len() outputs a integer
