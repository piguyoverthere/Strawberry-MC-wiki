Chiseled Cauldrons [technical]

The Chiseled Cauldron (strawberrymc:chiseled_cauldron) is an unbreakable, waterloggable basin block. It is the target block for spell vials; see Spells For Chiseled Cauldrons and the main Chiseled Cauldrons page.

Registration

The block is defined in block/ChiseledCauldronBlock.java, generated from elements/ChiseledCauldron.mod.json, and registered in init/StrawberrymcModBlocks.java with register("chiseled_cauldron", ChiseledCauldronBlock::new). init/StrawberrymcModItems.java creates its block item with new Item.Properties().stacksTo(1).rarity(Rarity.RARE). The lang key is item.strawberrymc.chiseled_cauldron.

init/StrawberrymcModTabs.java lists the item in three creative tabs:

  • The mod's Debug tab (strawberrymc:debug).
  • CreativeModeTabs.FUNCTIONAL_BLOCKS.
  • CreativeModeTabs.OP_BLOCKS, inside the tabData.hasPermissions() check.

The element file stores "unbreakable": true, which is the setting that produces the strength(-1, 3600000) call; its hardness of 1.0 and resistance of 10.0 fields do not appear in the generated class. getBlockPathType returns PathType.BLOCKED, so mobs path around the block.

Collision and outline shape

SHAPE is a Shapes.or union of five boxes that form a hollow basin with a 5-pixel floor and 2-pixel walls. getShape returns this union, and getVisualShape returns Shapes.empty().

Waterlogging

The block implements SimpleWaterloggedBlock and adds BlockStateProperties.WATERLOGGED, defaulting to false. The logic is spread over three overrides:

  1. getStateForPlacement sets the property to true when the fluid at the clicked position is Fluids.WATER.
  2. getFluidState returns Fluids.WATER.getSource(false) while waterlogged, and otherwise defers to super.
  3. updateShape schedules a water tick with Fluids.WATER.getTickDelay(world) while waterlogged, so the contained water keeps flowing into neighboring spaces.

Ambient particle call

animateTick calls AmbientParticleEnchantProcedure [raw] with the block's position. The procedure requests five ParticleTypes.ENCHANT particles with spreads of 0.5, 0.8 and 0.5 and a speed of 1:

public static void execute(LevelAccessor world, double x, double y, double z) {
	if (world instanceof ServerLevel _level)
		_level.sendParticles(ParticleTypes.ENCHANT, x, y, z, 5, 0.5, 0.8, 0.5, 1);
}

Spell interaction

The block has no useItemOn or useWithoutItem override. Interaction is driven from the item side: SmiteVialItem.useOn calls SmiteHandlerProcedure [raw], which compares the clicked block against StrawberrymcModBlocks.CHISELED_CAULDRON. That flow is described in Spells For Chiseled Cauldrons.
