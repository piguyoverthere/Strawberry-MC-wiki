Ores And Minerals [technical]

Overview

This page covers the code behind Ores And Minerals. The mod adds two generated ores, Radonite and Chorite, and replaces the loot of the emerald ores. It also adds Sulfur Slag. Gem and crystal materials are documented on Crystals [technical]. Blocks are registered in StrawberrymcModBlocks, items in StrawberrymcModItems, and all of them are generated from MCreator elements.

All four are in minecraft:mineable/pickaxe and use requiresCorrectToolForDrops. The two ore blocks use NoteBlockInstrument.BASEDRUM, and the two storage blocks use SoundType.METAL. Each loot table has one pool with one roll and the minecraft:survives_explosion condition, without a silk touch branch.

	}
}

World generation

Both ores are minecraft:ore configured features with discard_chance_on_air_exposure of 0. Each is added to biomes by a NeoForge add_features biome modifier in the underground_ores step.

FeatureBiomesReplacesVein sizeCount per chunkHeight (uniform)
strawberrymc:radonite_ore#is_overworldTag stone_ore_replaceables7111 to 63
strawberrymc:chorine_oreend_highlandsminecraft:end_stone6110 to 70

The placement order for both is count, in_square, height_range, then biome:

{
  "feature": "strawberrymc:radonite_ore",
  "placement": [
    { "type": "minecraft:count", "count": 11 },
    { "type": "minecraft:in_square" },
    { "type": "minecraft:height_range", "height": { "type": "minecraft:uniform", "min_inclusive": { "absolute": 1 }, "max_inclusive": { "absolute": 63 } } },
    { "type": "minecraft:biome" }
  ]
}

Radonite equipment

All five tools share a ToolMaterial built from BlockTags.INCORRECT_FOR_IRON_TOOL, durability 250, mining speed 6, attack bonus 0 and enchantment value 14. Each class defines its own material instance with its own repair tag, and each tag contains strawberrymc:radonite_ingot.

Emerald ore override

The elements EmeraldOreOverride.mod.json and DeepslateEmeraldOreOverride.mod.json generate data/minecraft/loot_table/blocks/emerald_ore.json and deepslate_emerald_ore.json. Those files replace the vanilla tables, so the ores never drop emeralds directly.

Sulfur Slag

strawberrymc:sulfur_slag is SulfurSlagItem. Its useOn calls SulfurFertilizeFarmlandProcedure [raw] and returns InteractionResult.SUCCESS. The farmland behavior is documented on Poor And Fertile Farmland [technical]. The item also upgrades normal fire through Tall Fire.

Three villager trades use it. Their JSON files are under data/strawberrymc/villager_trade, and they join the trade pools through the tags minecraft:farmer/level_2 and minecraft:toolsmith/level_1.
