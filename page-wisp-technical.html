Wisp [technical]

Spawning

Current spawning

The wisp currently spawns in groups of 4-10 with a spawn weight of 1 (no other mobs spawn in the Voidstone Peaks). (This is not intended behavior and will be changed with the addition of the Convoluted Waypoint

Future spawning

The wisp will spawn constantly in Convolution Points[coming soon] whenever there are less that 30 wisps within a 32x200x32 radius of the Confused Cauldron[rename][coming soon]

AI

Technically, wisps have no AI. Instead, they have a procedure called DoWispAIProcedure. Pseudocode for this AI is shown here:

Every tick per wisp:
Save the wisp's position into SavedData
If a 20-sided dice does not roll one and wisp is not in FOV of a player, end the program to prevent lag
If wisp is in a non-Voidstone Peaks biome AND gamerule doExternalWispGreifing is disabled, end the program
Repeat until a valid teleportation position is reached:
    Choose a random location in a 32x10x32 box
    Check whether block at this location is not air; if so, end and try again
    Check whether block at this location is farther than 6 blocks away from a solid block; if so, end and try again
Teleport to location
If a 50-sided dice rolls as 1{
  Delete the currently held block
  If that block was flammable, attempt to place fire
If possible, place a block anywhere within a 6x6x6 area around current position, block must have a supporting block on the bottom or side
If possible, take a block from anywhere within a 6x6x6 area around current position, prioritizing non-Voidstone blocks {
  Preserve block data (note: this is a great way to get illegal block states!)
  Have a higher chance of placing at higher altitudes
  If this block is a brewing stand with empty bottles, fail to pickup and become captured in bottle
}

Vibrations

Also, wisps have vibration sensitivity. All wisps will be saving their position to SavedData constantly. There are no particles created, but wisps will receive vibrations and run this pseudocode:

// Java goes here
Recursive method:
  Repeat at all wisps expected in SavedData within 32 blocks of (x,y,z):
    If this wisp is already in the hierarchy, end program
    Add this wisp to the hierarchy (with parent as the wisp who activated it)
    Send packet data to the wisp if they are in a loaded chunk
    Run this method as the position of the wisp as (x,y,z)
--------------------------------------------------------------------------------------------------
On vibration recieved:
If vibration type is 1, 2, 4, 7, 8, 12, 13, 14, or 15, end program
If vibration source is another wisp, end program
Create a new hierarchy
Run recursive method
If in a loaded chunk, replay/echo vibration
