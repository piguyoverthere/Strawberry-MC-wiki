Crystals [technical]

Overview

The crystal family has a cluster block and a solid block for each of five materials. Amethyst, the sixth type in world generation, uses vanilla minecraft:amethyst_cluster and minecraft:amethyst_block. All blocks are registered in StrawberrymcModBlocks and generated from MCreator elements such as CitrineCrystal.mod.json and CitrineBlock.mod.json.

The five classes have the same structure and vary only in strength and light level. Each extends Block and implements SimpleWaterloggedBlock, with sound AMETHYST_CLUSTER, no occlusion, and no redstone conduction.

public AquamarineCrystalBlock(BlockBehaviour.Properties properties) {
	super(properties.sound(SoundType.AMETHYST_CLUSTER).strength(1.5f).lightLevel(s -> 10).noOcclusion().isRedstoneConductor((bs, br, bp) -> false));
	this.registerDefaultState(this.stateDefinition.any().setValue(FACING, Direction.NORTH).setValue(WATERLOGGED, false));
}

States and placement

Clusters have a FACING property with all six directions and a WATERLOGGED boolean. getStateForPlacement sets the facing to the clicked face and waterlogs the block when placed in water. updateShape schedules a water tick while waterlogged, and getFluidState returns a water source in that state.

The collision box is a 10 by 10 pixel prism, 13 pixels long. getVisualShape returns an empty shape, getLightDampening returns 0, and propagatesSkylightDown is true when the block is not waterlogged.

Model

Each cluster's block model has the parent strawberrymc:custom/crystal_cluster. The blockstate rotates it by facing: north 0, east y 90, south y 180, west y 270, up x 270 and down x 90.

Clusters and solid blocks each drop themselves through a loot table with the minecraft:survives_explosion condition.

Cinnabar

strawberrymc:cinnabar is CinnabarBlock, with hardness 1.5 and resistance 6. It forms the bed of the hollows_pool feature and drops itself.

The column is built by CrystalColumnGenerationProcedure [raw], which picks its material from a random integer 1 to 6:

pick = Mth.nextInt(RandomSource.create(), 1, 6);
if (pick == 1) {
	mat = Blocks.AMETHYST_BLOCK.defaultBlockState();
} else if (pick == 2) {
	mat = StrawberrymcModBlocks.GARNET_BLOCK.get().defaultBlockState();
} else if (pick == 3) {
	mat = StrawberrymcModBlocks.DENDRITE_BLOCK.get().defaultBlockState();
} else if (pick == 4) {
	mat = StrawberrymcModBlocks.CITRINE_BLOCK.get().defaultBlockState();
} else if (pick == 5) {
	mat = StrawberrymcModBlocks.AQUAMARINE_BLOCK.get().defaultBlockState();
} else {
	mat = StrawberrymcModBlocks.ROSE_QUARTZ_BLOCK.get().defaultBlockState();
}
