Ancient Prismarine [technical]

Overview

Ancient Prismarine and Cracked Prismarine are simple cube blocks with no block entity or custom block behavior. Their roles in the Ocean Monument come from code that tests for them by block type: MonumentShell places them on the roof, and PrismaticSensors reacts when they are broken.

Ancient Prismarine's loot table, data/strawberrymc/loot_table/blocks/ancient_prismarine.json, rolls once with a minecraft:survives_explosion condition and drops the block's own item.

Ancient Prismarine in the monument

The vent cap is 9 blocks, a 3x3 set into the gazebo floor at floorY, centerd on the gazebo.

public List<BlockPos> ventCap() {
	List<BlockPos> cap = new ArrayList<>();
	for (int dx = -1; dx <= 1; dx++)
		for (int dz = -1; dz <= 1; dz++)
			cap.add(new BlockPos(centerX() + dx, floorY, centerZ() + dz));
	return cap;
}

Beneath it is a 3x3 shaft of water, 3 deep, with minecraft:soul_sand at depth 4, so a bubble column rises once the cap is removed.

Exemption from the sensors

PrismaticSensors.isExempt returns true for Ancient Prismarine, for both breaking and placing. It is the only block a survival player can change inside a monument with active Prismatic Sensors.

private static boolean isExempt(@Nullable Player player, BlockState state) {
	return player == null || player.isCreative() || player.isSpectator() || state.is(StrawberrymcModBlocks.ANCIENT_PRISMARINE.get());
}

Vent trigger

After an exempt break, onBreak calls checkVent whenever the broken block is Ancient Prismarine. The rest of the sequence is on Ocean Monument.

private static void checkVent(ServerLevel level, BlockPos pos) {
	MonumentShell.Layout layout = monumentAt(level, pos);
	if (layout == null || !layout.ventCap().contains(pos) || ERUPTING.contains(layout.ventCenter()))
		return;
	// Only once: after the jet the dome is gone
	if (!level.getBlockState(layout.lumpCenter()).is(StrawberrymcModBlocks.CRACKED_PRISMARINE.get()))
		return;

Any one of the 9 cap blocks starts the eruption. Further cap blocks broken during it, or after the dome is gone, do nothing.

Cracked Prismarine in the monument

Cracked Prismarine forms an upside-down dome under the gazebo's copper roof. Layout.lump() lists its blocks using a sphere test, with DOME_RADIUS 3.6 and DOME_DEPTH 3.

int r = (int) Math.ceil(DOME_RADIUS);
for (int dy = 0; dy <= DOME_DEPTH; dy++)
	for (int dx = -r; dx <= r; dx++)
		for (int dz = -r; dz <= r; dz++)
			if (dx * dx + dz * dz + dy * dy <= DOME_RADIUS * DOME_RADIUS)
				lump.add(new BlockPos(centerX() + dx, domeTop() - dy, centerZ() + dz));

Cracked Prismarine has no sensor exemption, so survival players cannot mine it while its quadrant's sensor is active. The jet removes it at tick 70 (3.5 seconds) of the eruption. shatter calls level.destroyBlock(pos, false) on each remaining dome block, so the dome drops no items.

Reset

PrismaticSensors.resetVent runs from /cutscene clear for a player inside a monument. It clears the monument's ERUPTING entry, sets the 3 blocks beneath each cap position to water, puts Ancient Prismarine back in all 9 cap positions, and places Cracked Prismarine at every position in Layout.lump(), all with Block.UPDATE_ALL. The vent cutscene can then play again.
