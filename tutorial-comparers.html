Comparers and Logic

Comparers

Comparers in ComScript are booleans that have outputs dependent on comparing two values, such as if two values or equal or greater than the first value. Basic native comparers are listed below:

Comparer syntaxActionNotes
==Is exactly equal to?
~=Is approximately equal to?Used in examples such as the true statement "a ~= A".
>Greater than value 2?
<Lesser than value 2?
>=Greater than or equal to value 2?Other syntax such as => causes a syntax error, an easy way to remember is that "greater than equal to" starts with "greater" and ends with "equal".
<=Lesser than or equal to value 2?Other syntax such as =< causes a syntax error, an easy way to remember is that "lesser than equal to" starts with "lesser" and ends with "equal".
containsDoes value 1 contain value 2?The contains boolean checks for a string or character within a larger string, such as if "apple" contains "a", which would be true. This character can be a different state, such as "apple" contains "A".
