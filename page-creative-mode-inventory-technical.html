Creative Mode Inventory [technical]

Overview

This page covers the code behind Creative Mode Inventory. StrawberrymcModTabs, generated by MCreator, does two jobs: it registers one custom tab, and it adds mod items to the vanilla tabs. Tall Fires are documented in their own section below.

Developer tab

The custom tab is registered through a DeferredRegister for Registries.CREATIVE_MODE_TAB under the ID strawberrymc:debug. StrawberrymcMod registers that REGISTRY on the mod event bus. Its title key is item_group.strawberrymc.debug, "Developer", its icon is a Command Block, and it has a search bar.

public static final DeferredHolder<CreativeModeTab, CreativeModeTab> DEBUG = REGISTRY.register("debug",
		() -> CreativeModeTab.builder().title(Component.translatable("item_group.strawberrymc.debug")).icon(() -> new ItemStack(Blocks.COMMAND_BLOCK)).displayItems((parameters, tabData) -> {
			tabData.accept(StrawberrymcModBlocks.OASIS_SPAWNER.get().asItem());
			// ... remaining entries
		}).withSearchBar().build());

Vanilla tabs

buildTabContentsVanilla subscribes to BuildCreativeModeTabContentsEvent and compares tabData.getTabKey() in one if / else if chain, then calls tabData.accept for each entry. MCreator writes these entries from the creativeTabs list of each element. The same item can be listed in more than one tab, as garnet_block is in Building Blocks, Natural Blocks and Colored Blocks.

Tall Fires

Block

Tall Fire is strawberrymc:tall_fire, implemented by TallFireBlock, which extends FireBlock. Ticking, spreading and survival rules are inherited from that class. Its element is TallFire.mod.json, and its block item appears in the Developer tab.

public TallFireBlock(BlockBehaviour.Properties properties) {
	super(properties.sound(SoundType.GRAVEL).strength(1f, 10f).noCollision().isRedstoneConductor((bs, br, bp) -> false).replaceable());
}

@Override
public void onPlace(BlockState blockstate, Level world, BlockPos pos, BlockState oldState, boolean moving) {
	super.onPlace(blockstate, world, pos, oldState, moving);
	world.scheduleTick(pos, this, 10);
}

Ignition

Two event-driven procedures turn Blocks.FIRE into Tall Fire.

TallFireIgniteHandlerProcedure [raw] subscribes to PlayerInteractEvent.RightClickBlock for the main hand. If the clicked block is fire and the main hand holds strawberrymc:sulfur_slag, it replaces the block with Tall Fire, shrinks the held stack by 1 and cancels the event.

TallFireNaturalIgniterProcedure [raw] subscribes to BlockEvent.EntityPlaceEvent. When the placed position is fire, it counts how many of the six neighbors are also fire:

if (fire_tracking >= 2 && Math.random() < 0.5) {
	world.setBlock(BlockPos.containing(x, y, z), StrawberrymcModBlocks.TALL_FIRE.get().defaultBlockState(), 3);
}
if at least 2 neighbouring blocks are fire, with a 50% chance:
    replace this block with tall fire

At least 2 adjacent fire blocks gives a 50% chance of conversion.

Element procedures

TallFire.mod.json names four trigger procedures. TallFireBlock overrides only onPlace, propagatesSkylightDown, getLightDampening, getVisualShape and getCloneItemStack, and no class calls these four procedures, so their code runs only if invoked directly.

Element triggerProcedureCode
onTickUpdateTallFireTickingProcedure [raw]In rain with sky above, sets the block to air. Otherwise it rolls integer coordinates from -6 to 6 fifteen times, keeps the last roll and places fire at those absolute coordinates, without adding the block's own position
onRandomUpdateEventTallFireParticleEmitterProcedure [raw]Sends LAVA particles at the block center, spread 0.5, in a loop bounded by a random integer from 2 to 5
onEntityCollidesTallFireDamageProcedure [raw]Deals 3 damage of type DamageTypes.IN_FIRE and sets the entity on fire for 6 seconds
onRightClickedTallFireExtinguishProcedure [raw]Unless the main hand holds Sulfur Slag, replaces the block with Blocks.FIRE and plays block.fire.extinguish
