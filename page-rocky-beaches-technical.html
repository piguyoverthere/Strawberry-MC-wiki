Rocky Beaches [technical]

The mod's Rocky Beaches code is the Glowroot plant: a two-block system of a tuber in stone and a glowing plant on top.

Blocks and item

IDClassProperties
strawberrymc:glowrootGlowrootBlock, a FlowerBlockHardness 0, resistance 1, light 15, emissive, no collision, XZ offset, push reaction DESTROY
strawberrymc:glowroot_tuber_stoneGlowrootTuberStoneBlockHardness 1.5, resistance 6, requires correct tool, pickaxe, push reaction DESTROY, bone-mealable
strawberrymc:glowroot_dummy_spawnerGlowrootDummySpawnerBlock, a FlowerBlockHardness 10, resistance 10, light 15, emissive, flammability 100, fire spread 60
strawberrymc:glowroot_tuberGlowrootTuberItemRarity UNCOMMON, enchanted foil

GlowrootBlock and the dummy spawner both restrict mayPlaceOn and canSurvive to a block of glowroot_tuber_stone directly below. GlowrootBlock.getCloneItemStack returns the tuber stone.

Planting and growth

  1. GlowrootTuberItem.useOn runs GlowrootTuberPlantProcedure [raw]. If the clicked block is exactly minecraft:stone, it becomes glowroot_tuber_stone and the sound item.crop.plant plays.
  2. GlowrootTuberStoneBlock implements BonemealableBlock with isBonemealSuccess always true.
  3. performBonemeal runs GlowrootTuberGrowProcedure [raw], which sets a glowroot one block above.
public static void execute(LevelAccessor world, double x, double y, double z) {
	world.setBlock(BlockPos.containing(x, y + 1, z), StrawberrymcModBlocks.GLOWROOT.get().defaultBlockState(), 3);
}

GlowrootHavestProcedure [raw] is a standalone procedure that no block or item calls. When executed with a hoe in slot 98 of the passed item stack's item capability, it replaces the block with stone, plays item.crop.plant and spawns one tuber.

World generation

elements/GlowrootDummyPatch.mod.json generates the placed feature strawberrymc:glowroot_dummy_patch. Its biome modifier uses neoforge:any and the step surface_structures, so the placed feature's own filters are the only limit.

Placement stepValue
minecraft:rarity_filterchance 6 (1 in 6 chunks)
minecraft:in_squareRandom x and z in the chunk
minecraft:heightmapMOTION_BLOCKING
minecraft:biomeMust be a biome holding the feature

The configured feature is a simple_random_selector with one inline placed feature. That feature is a minecraft:block_column of one layer, height 1, placing strawberrymc:glowroot_dummy_spawner into air, moved by 5 tries with a random_offset of ±7 horizontally and ±3 vertically.

Dummy spawner conversion

GlowrootDummySpawnerBlock.onPlace runs GlowrootGenerationProcedure [raw]. If the block below is in minecraft:base_stone_overworld, the procedure replaces it with glowroot_tuber_stone and replaces the spawner with a real glowroot.

if ((world.getBlockState(BlockPos.containing(x, y - 1, z))).is(BlockTags.create(Identifier.parse("minecraft:base_stone_overworld")))) {
	world.setBlock(BlockPos.containing(x, y - 1, z), StrawberrymcModBlocks.GLOWROOT_TUBER_STONE.get().defaultBlockState(), 3);
	world.setBlock(BlockPos.containing(x, y, z), StrawberrymcModBlocks.GLOWROOT.get().defaultBlockState(), 3);
}
