Changelog

Updates and patches to the wiki website, newest first. Update means something new was added; Patch means something was fixed or tidied up. Changes to the articles themselves are in each page's 🕘 History and under Changes on the Notifications page.

November 12, 2026

  • Update — Changelog. This page, listed under the Wiki menu.
  • Update — Notifications and Changes tabs. The Notifications page is split in two. Notifications only shows what concerns you: replies and votes on your ideas, threads and bug reports, replies in conversations you're part of, changes to your bookmarked pages, what the people you follow do, and anything that names you. Changes lists everything that happens on the wiki.
  • Update — Version history. Every page has a 🕘 History button showing each change from the last 30 days as a git-style diff, with added lines in green and removed lines in red. Admins can restore an older version; editors and reviewers can ask an admin to restore one.
  • Patch — Thread links. Clicking a thread or debate in notifications now opens that thread instead of the top of the Threads & Debates page.
  • Patch — Closing the history. The version history has an × button in its corner, and clicking outside it or pressing Esc closes it too.

November 11, 2026

  • Update — Profiles. Everyone has a profile page with a bio, links, pictures, pronouns, a status, a Minecraft username, favourite pages, activity counts, and following and followers.
  • Update — Settings. The settings on your profile cover dark mode, text size, font, page width, underlined links, reduced motion, which code tab opens first, the Contents box, spell-check, notifications, privacy, your password and password recovery. They follow you to other devices.
  • Update — Password recovery. Confirm an email address to reset a forgotten password with an emailed code, or ask an admin for a temporary password.
  • Update — Changing the wiki password. Admins can change the wiki password from the Admin page, after confirming twice.
  • Update — @ pings in idea comments. Type @ and a name to ping someone; it shows on their Notifications.
  • Update — Completed ideas. Ideas can be marked as completed and have their own Completed tab. Ideas scoring above 2 with no votes or edits for over a day are highlighted as ready to implement.
  • Update — Pseudocode. Every Java code box has a Pseudocode tab explaining the code in plain steps.
  • Update — Headings 5 and 6, and lettered sub-lists. Two more heading sizes, and lists inside numbered lists count a, b, c.
  • Patch — Code boxes. Code keeps its indentation with 4-wide tabs and no line wrapping, and the open tab is clearer.
  • Patch — Editor bar. The editing toolbar is more compact.
  • Patch — Inserting. Recipes, diagrams and other inserts no longer land at the end of the page, and editing keeps your place.

November 10, 2026

  • Update — Recipes and block diagrams. Insert crafting recipes and block diagrams while editing, where the cursor is. Element names link to their pages automatically.
  • Update — Mark as unresolved. Flag a page that is incomplete or wrong so it lands on the To Do list.
  • Update — Tables. Buttons to add and remove table rows and columns.
  • Update — Needs convincing votes. Ideas can be voted Approve, Disapprove or Needs convincing, and links go straight to the exact idea.
  • Update — Editing ideas. The person who posted an idea, and admins, can edit it.
  • Update — About page. A blank About page beside Home in the top bar.
  • Update — Login wall. The wiki stays hidden until the reader logs in or enters the wiki password. The login page has no top bar and can't be edited.
  • Patch — Links. Links between wiki pages are relative, so they work on any domain.

November 9, 2026

  • Update — Page comments. Select text in an article to comment on it. Naming someone with @ gives them a priority task.
  • Update — Live updates. New comments, replies and votes appear without reloading.
  • Update — PDF versions. Upload new versions of the PDFs from the PDF Documents page. Versions are sorted by creation date, which can be set by hand.
  • Update — All Pages. An A to Z list of every page, under the Wiki menu.
  • Patch — Wiki bugs #3 to #7. Fixed double posts, deleting ideas, the Archives page, the To Do list, and a too-narrow review view.
  • Patch — PDF uploads. PDFs with extra bytes before the header are accepted, and rejected uploads say why.

November 8, 2026

  • Update — Technical pages. Procedure and technical pages with code for the mod's features.
  • Patch — Republishing pages. Pages created on the website can be committed again.
  • Patch — Remove all styles. Also clears the box around pasted code.

November 6, 2026

  • Update — Accounts and roles. Accounts with admin, editor and reviewer roles; reviewers' changes wait for approval.
  • Update — Bug Tracker. Report and track problems with the wiki.
  • Update — PDF Documents page and HTML blocks. The Open PDF button leads to every PDF and its older versions, and editors can insert raw HTML blocks.
  • Update — Ideas and Threads & Debates. Pages for ideas and discussions from the MC Controversy Resolver, with approval votes from the original document.
  • Update — Notifications. A page listing every update to the wiki.
  • Update — Timestamps and sign-in. Posts and comments show when they were made, and you sign in once instead of on every post.
  • Update — Sign out. A Sign out button in the top bar while signed in.

November 5, 2026

  • Update — New look. A Minecraft Wiki-style background, Wikipedia-style text, a centred search bar, paper-style pages and floating page tools.
  • Update — Wiki password. Editors commit changes with the wiki password instead of a GitHub token.
  • Update — Merged pages. Subtopic pages were merged into their main topics, with consistent See also links.
  • Patch — Fresh files. The site reloads once when it has newer files than the browser's cache.
  • Patch — Browser extensions. Code added by browser extensions is kept out of saved pages and was removed from 9 pages.
  • Patch — Cut-off text. Repaired text that had been cut off in several pages.

November 4, 2026

  • Update — Editing on the website. A New page button, saving changes straight to GitHub, and a formatting bar.
  • Update — News. A News tab with articles by their authors.
  • Update — Waiting page. A custom "page not found" page that waits for newly created pages to go live.
  • Update — Remove all styles. A button in the editor bar that clears formatting.
  • Patch — Lists. Backspace at the start of a list item removes the bullet first, then joins the line.

October 30, 2026

  • Update — Launch. The wiki went online with the pages from the Strawberry MC wiki document.
