Desert [technical]

The mod's Desert code covers palm trees, coconuts and coconut oil. The pools placed around palm trees are covered under Oases.

The palm feature

elements/Palm.mod.json generates three data files.

FileContent
configured_feature/palm.jsonminecraft:tree built from minecraft:oak_log and minecraft:oak_leaves
placed_feature/palm.jsonOne minecraft:block_predicate_filter: would_survive for minecraft:cactus
biome_modifier/palm_biome_modifier.jsonAdds the placed feature to minecraft:desert, step surface_structures
 
{
  "feature": "strawberrymc:palm",
  "placement": [
    {
      "type": "minecraft:block_predicate_filter",
      "predicate": {
        "type": "minecraft:would_survive",
        "state": { "Name": "minecraft:cactus" }
      }
    }
  ]
}

The placement list has no count, in_square or heightmap step, so the filter is evaluated once per chunk at the chunk's origin, at the bottom of the world (ChunkGenerator.applyBiomeDecoration starts from SectionPos.of(centerPos, level.getMinSectionY()).origin()). CactusBlock.canSurvive needs a block in BlockTags.SUPPORTS_CACTUS or another cactus below, and the block below the lowest layer is outside the world, so the filter does not pass there.

Procedural palm tree

SpawnPalmTreeProcedureProcedure [raw] builds the tree used by oases out of PALM_LOG and PALM_LEAVES with PERSISTENT set to true. It writes with world.setBlock flag 3 and does not check for free space.

  1. Trunk. Height is 8 + random.nextInt(6), so 8 to 13 blocks. A single tilt of -1 to 1 per axis is rolled for the whole tree. From the fourth log up, each log has a 35% chance to shift the trunk by that tilt.
  2. Crown core. Leaves go at 1 and 2 blocks above the top log. The 8 surrounding positions at level 1 are always filled, and those at level 2 are filled with 60% chance.
  3. Fronds. Eight directions each grow a frond. Straight fronds are 3 or 4 blocks long, diagonal fronds 2 or 3. The first step sets a height offset of 1 or 2, and the last step lowers it by 1.
  4. Frond volume. Each frond block has a 50% chance of a leaf below it, and straight fronds have a 40% chance of a side leaf.
  5. Tips. The last block hangs 1 or 2 extra leaves downward, each with a 30% chance of a side leaf.
int height = 8 + random.nextInt(6);
int tiltX = random.nextInt(3) - 1;
int tiltZ = random.nextInt(3) - 1;
int currentX = (int) x;
int currentZ = (int) z;

for (int i = 0; i < height; i++) {
    world.setBlock(BlockPos.containing(currentX, y + i, currentZ), log, 3);
    if (i >= 3 && random.nextFloat() < 0.35f) {
        currentX += tiltX;
        currentZ += tiltZ;
    }
}

Sapling growth

PalmSaplingBlock implements BonemealableBlock with isBonemealSuccess always true. PalmGrowProcedure [raw] places the configured feature strawberrymc:palm at the sapling, so a bone-mealed sapling produces the oak-block tree from configured_feature/palm.json. The sapling drops one strawberrymc:plant_fiber.

Coconut

CoconutItem (strawberrymc:coconut) stacks to 64 and is both a thrown projectile and the way to plant a palm.

Planting

Right-clicking a block runs CoconutPlantProcedure [raw]. If the clicked block is sand or red sand, a palm_sapling is set one block above it.

if ((world.getBlockState(BlockPos.containing(x, y, z))).getBlock() == Blocks.SAND
		|| (world.getBlockState(BlockPos.containing(x, y, z))).getBlock() == Blocks.RED_SAND) {
	world.setBlock(BlockPos.containing(x, y + 1, z), StrawberrymcModBlocks.PALM_SAPLING.get().defaultBlockState(), 3);
}

Throwing

The item's use animation is BLOCK with a use duration of 1 tick. use starts the action if the player is in creative mode or findAmmo finds a coconut in the inventory. releaseUsing calls CoconutProjectileEntity.shoot and removes one coconut outside creative mode.

tick discards the projectile once it is in the ground. onHitBlock runs CoconutImpactParticleHandlerProcedure [raw], which sends 5 strawberrymc:coconut_impact particles with a spread of 1 on each axis. The particle element has a maxAge of 7, gravity 0.7, and collides with blocks.

PlantCoconutProcedure [raw] is a separate procedure that no item or block calls. Its branch for sand, red sand and gravel sets radonite_ore one block above.

Coconut Oil

CoconutOilItem stacks to 16. The recipe coconut_oil_recipe.json is shapeless: one strawberrymc:coconut and one minecraft:glass_bottle make one strawberrymc:coconut_oil.
