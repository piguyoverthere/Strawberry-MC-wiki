Admin Settings

People with admin or operator permisions have access to an admin lobby, which has rooms with switches the admin or operator can alter affecting the entire world. These settings are physical levers. Admin lobbies also contain helpful debug information with fps, and more.


All levers correspond to different gamerules, including ones both listed in the settings menu and additional/hidden settings. Any settings that requires a dropdown bar, number input, or multi-stage toggle have corresponding custom block displays.
