Crystalline Calcite [technical]

Block class

Crystalline Calcite is strawberrymc:crystalline_calcite, implemented by CrystallineCalciteBlock. It is a directional half-thick layer that faces the side it was placed on: flat on floors, hanging on ceilings and upright on walls.

public CrystallineCalciteBlock(BlockBehaviour.Properties properties) {
	super(properties.sound(SoundType.CALCITE).strength(1f, 10f).noOcclusion().isRedstoneConductor((bs, br, bp) -> false));
	this.registerDefaultState(this.stateDefinition.any().setValue(FACING, Direction.UP));
}

Shape and placement

makeShapes precomputes one 8-pixel-thick box per facing. getStateForPlacement sets FACING to the clicked face, and rotate and mirror transform it.

return switch (state.getValue(FACING)) {
	case DOWN -> box(0, 8, 0, 16, 16, 16);
	case NORTH -> box(0, 0, 8, 16, 16, 16);
	case SOUTH -> box(0, 0, 0, 16, 16, 8);
	case EAST -> box(0, 0, 0, 8, 16, 16);
	case WEST -> box(8, 0, 0, 16, 16, 16);
	default -> box(0, 0, 0, 16, 8, 16);
};

Model

The blockstate file lists several randomly chosen variants for each facing, using rotations of the models crystalline_calcite, crystalline_calcite_2 and crystalline_calcite_3. These inherit from strawberrymc:custom/crystalline_calcite, custom/crystalline_calcite_2 and custom/crystalline_calcite_3.

Interaction with carving

The cavern carver treats the block as carvable, explicitly checking for it, because the surface rule has already laid it on the floors of vanilla caves and it would otherwise be left floating over the cavern. Vanilla cave carvers do not count it as carvable, so the calcite_cleanup feature in CrystalHollowsDecor removes any Crystalline Calcite with an empty block below it, once per chunk in step raw_generation.

Other features that use it

  • It is in the tag #strawberrymc:hollows_ground, so crystal patches and pools can replace it.
  • hollows_scattered_crystals scans for it and places individual crystals in its position when a solid block is below.
