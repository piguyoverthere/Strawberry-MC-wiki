Crafting Tables

Tabs

To compensate and keep the Crafting Table organized while still allowing it to retain many uses in this mod, the Crafting Table now has static tabs located on a bar. [UNRESOLVED] The source text is truncated after “at”.

These tabs group the different things that can be crafted, such as blocks and items. The Forging tab remains locked when a Crafting Table is crafted. It must be unlocked by putting the Crafting Table in another Crafting Table and combining it with 3 Cobblestones in any of the cardinal directions of the crafting grid, a Forging Hammer filling the last cardinal direction, and 4 Metal Ingots [source text truncated].

The Forging tab allows players to forge weapons or equipment from any Metal they have, or combine Metals to form alloys with special properties, using the Crucible tool. The Forging section of the Crafting Table requires a temperature of 1,300 degrees, and all tools require this heat. In Forging mode, the recipe book in Java Edition or the sidebar in Bedrock Edition displays forgeable recipes and alloys in 2 subtabs. The player can select an option and provide a fuel source to create the alloy or equipment. Each recipe takes 15 seconds to forge.
