Forests [technical]

The mod's Forests code is the talus slope feature and the Juniper wood family.

Forest talus slope feature

elements/ForestTalusSlope.mod.json generates a configured feature, a placed feature and a biome modifier. It is a vanilla minecraft:ore feature with two targets and no Java code.

FileContent
configured_feature/forest_talus_slope.jsonminecraft:ore, size 50, discard_chance_on_air_exposure 0
placed_feature/forest_talus_slope.jsonOne minecraft:biome filter
biome_modifier/forest_talus_slope_biome_modifier.jsonneoforge:any biomes, step surface_structures
 
"targets": [
  { "target": { "predicate_type": "tag_match", "tag": "ore" },
    "state": { "Name": "minecraft:cobblestone" } },
  { "target": { "predicate_type": "tag_match", "tag": "ore" },
    "state": { "Name": "minecraft:gravel" } }
]

Both targets use the block tag minecraft:ore. Neither vanilla nor the mod defines a tag with that name, so the rule test matches no blocks. The placement list has no count, in_square or height step, so one attempt per chunk runs at the chunk's origin at the bottom of the world.

Juniper wood family

Juniper is a complete MCreator wood set made of 34 element files. Registration happens in StrawberrymcModBlocks, StrawberrymcModItems and StrawberrymcModEntities, and StrawberrymcModWoodTypes registers strawberrymc:juniper_sign and strawberrymc:juniper_hanging_sign on BlockSetType.OAK.

juniper_log2 / 25 / 5Axe
juniper_leaves0.2 / 0.260 / 30Hoe

The other blocks are juniper_wood, stripped_juniper_log, stripped_juniper_wood, juniper_planks, juniper_stairs, juniper_slab, juniper_fence, juniper_fence_gate, juniper_door, juniper_trapdoor, juniper_pressure_plate, juniper_button, juniper_sign, juniper_wall_sign, juniper_hanging_sign and juniper_wall_hanging_sign. The entities juniper_boat and juniper_chest_boat are registered with their items.

Leaves

JuniperLeavesBlock extends UntintedParticleLeavesBlock with a leaf particle chance of 0 and a TINTED_LEAVES particle option colored -11181774. Its loot table has two pools. The first, for tools other than shears or Silk Touch, gives 1 to 2 sticks at the Fortune chances 0.02, 0.022222223, 0.025, 0.033333335, 0.1. The second gives the leaves with shears or Silk Touch, and otherwise gives leaves at the Fortune chances 0.05, 0.0625, 0.083333336, 0.1. elements/JuniperLeavesComposting.mod.json and data/neoforge/data_maps/item/compostables.json set a compost chance of 0.3.

Tags

The block and item tags strawberrymc:juniper_logs hold the log, wood, stripped log and stripped wood. The family is merged into these vanilla tags with "replace": false:

  • Items: minecraft:planks, minecraft:logs_that_burn, minecraft:boats, minecraft:chest_boats.
  • Blocks: minecraft:planks, minecraft:logs_that_burn, minecraft:leaves, minecraft:slabs, minecraft:stairs, minecraft:wooden_fences, minecraft:wooden_doors, minecraft:wooden_trapdoors, minecraft:wooden_buttons, minecraft:wooden_pressure_plates, minecraft:standing_signs, minecraft:wall_signs, minecraft:ceiling_hanging_signs, minecraft:wall_hanging_signs, minecraft:mineable/axe, minecraft:mineable/hoe.
  • Entity types: minecraft:boat.

Recipes

Each block has a recipe element named Juniper...Recipe, generated into data/strawberrymc/recipe/juniper_*_recipe.json, including juniper_boat_recipe.json and juniper_chest_boat_recipe.json.
