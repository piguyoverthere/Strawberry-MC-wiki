String operators

getlen(<string>)

The getlen() operator gets the length of the string provided, including spaces.

Example:

console.log(getlen("test"));
// Expected output would be 4.

getchar(<i>, <string>)

The getchar() operator has 2 inputs, one for a index integer and string. This operator outputs the a single character that corresponds to #<i> of the string, which means that the index must be lesser than or equal to the total length of the string.

Example:

console.log(getchar(4, "test"));
// Expected output would be t.

Conjoining strings, floats, integers, and data structures

ComScript allows for conjoining items with commas, such as:

store new answer = "3"
console.log("The answer is ", str($answer));

Notice how there is a empty space after "is" in the first element, this is so that the word "is" has a space in between it and the answer variable.

Conjoining is allowed in any input that uses strings, although only elements of the same data type can be conjoined, such as string and string, or integer and integer. You can use the data type converting formats to convert between each data type.
