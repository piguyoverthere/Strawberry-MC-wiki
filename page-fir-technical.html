Fir [technical]

The Fir tree is a feature generating exclusively in the AlpineMeadow biome [Alpine Meadowlands in-game]. Fir trees are made from Spruce Wood, Spruce Leaves, Spruce Logs, and Spruce Fences. Fir trees come in 3 variants listed below.

Fir

Fir trees are steeply triangular in shape, with bracts widest at the base and moving upwards. A java loop randomizes the bracts and adds a spire of Spruce Logs at the top.

Dead Fir

Dead Fir features have the same trunk and trunk base at the base of the logs, but has Spruce Fences extending sideways instead of Spruce Leaves.


Fir Snag

Fir Snag features have only a trunk and base decorators.

Base Decorators

Base Decorators are Spruce Wood blocks at the base that has a 60% chance to generate on the x and z axis. Each decorator can only be 1 block on each axis.
