Fir [technical]

The Fir tree is a feature generating exclusively in the AlpineMeadow biome [Alpine Meadow in-game]. Fir trees are made from Spruce Wood, Spruce Leaves, Spruce Logs, and Spruce Fences. Fir trees come in 3 variants listed below.

Fir

Fir trees are steeply triangular in shape, with bracts widest at the base and moving upwards. A java loop randomizes the bracts and adds a spire of Spruce Leaves at the top.

Dead Fir

Dead Fir features have the same trunk and trunk base at the base of the logs, but has Spruce Fences extending sideways instead of Spruce Leaves.


Fir Snag

Fir Snag features have only a trunk and base decorators.

Base Decorators

Base Decorators are Spruce Wood blocks at the base that has a 60% chance to generate on the x and z axis. Each decorator can only be 1 block on each axis.

The fir_tree feature

FirTree is a Feature<NoneFeatureConfiguration> registered as strawberrymc:fir_tree, placed in Alpine Meadowlands once per chunk. The origin is the first air block above the surface, and the trunk replaces the ground block below it. The ground must be in BlockTags.SUBSTRATE_OVERWORLD, which covers grass, dirt, podzol, moss and mud.

BlockPos ground = context.origin().below();

if (!level.getBlockState(ground).is(BlockTags.SUBSTRATE_OVERWORLD)) {
    return false;
}

DetermineRandFirProcedure.execute(level, ground.getX(), ground.getY(), ground.getZ());
return true;
if the block below is not overworld ground (substrate_overworld):
    stop without placing anything
run DetermineRandFirProcedure at the ground block
return true

Variant selection

DetermineRandFirProcedure [raw] makes up to two rolls of an integer from 1 to 100.

randint = Mth.nextInt(RandomSource.create(), 1, 100);
if (randint < 85) {
	FirGenerationProcedure.execute(world, x, y, z);
} else {
	randint = Mth.nextInt(RandomSource.create(), 1, 100);
	if (randint < 60) {
		DeadFirGenerationProcedure.execute(world, x, y, z);
	} else {
		FirSnagGenerationProcedure.execute(world, x, y, z);
	}
}
pick a random number from 1 to 100
if it is under 85 (about 84%):
    run FirGenerationProcedure
else:
    pick a new random number from 1 to 100
    if it is under 60 (about 59%):
        run DeadFirGenerationProcedure
    else:
        run FirSnagGenerationProcedure

Trunk and roots

All three procedures choose a height with 18 + (int)(Math.random() * 8), giving a trunk of 18 to 25 blocks of minecraft:spruce_log. Each of the four horizontal neighbors of the base has its own independent 60% chance of minecraft:spruce_wood.

if (Math.random() < 0.6) world.setBlock(BlockPos.containing(x + 1, y, z), Blocks.SPRUCE_WOOD.defaultBlockState(), 3);
if (Math.random() < 0.6) world.setBlock(BlockPos.containing(x - 1, y, z), Blocks.SPRUCE_WOOD.defaultBlockState(), 3);
if (Math.random() < 0.6) world.setBlock(BlockPos.containing(x, y, z + 1), Blocks.SPRUCE_WOOD.defaultBlockState(), 3);
if (Math.random() < 0.6) world.setBlock(BlockPos.containing(x, y, z - 1), Blocks.SPRUCE_WOOD.defaultBlockState(), 3);
for each of the 4 sides of the base:
    60% chance to place spruce wood as a root

FirGenerationProcedure

Foliage

Foliage starts 3 or 4 blocks up (3 + (int)(Math.random() * 2)) and runs to height - 3. Even heights are wide tiers and odd heights stay tight to the trunk, which produces the layered outline.

boolean isWideTier = (i % 2 == 0);

int radius;
if (isWideTier) {
    radius = (int) Math.ceil((double)(height - i) / 6.5);
} else {
    radius = 1;
}

if (radius < 1) radius = 1;
every other layer (even layers) is a wide tier
if this is a wide tier:
    the radius is (height - layer) / 6.5, rounded up
else:
    the radius is 1
the radius is at least 1

Dividing the remaining height by 6.5 narrows the tree toward the top, and the widest tier reaches 4 blocks from the trunk. Each position in the square other than the center is then filtered:

Corner, radius above 180%
Corner, radius 150%

Surviving positions become minecraft:spruce_leaves if empty.

Spire

A loop from height - 2 to height + 3 places spruce leaves in the trunk's column where the position is empty. The two lowest positions are already logs, leaving a 4-block spire of leaves above the trunk. The procedure then calls FirTreeFinisher.finish.

DeadFirGenerationProcedure

The trunk, roots, first tier and radius formula match the living fir. Branches use minecraft:spruce_fence and grow straight out from the trunk, because fences connect only sideways.

int[][] directions = {{1, 0}, {-1, 0}, {0, 1}, {0, -1}};
for (int[] dir : directions) {
    if (Math.random() < 0.65) continue;

    int length = 1 + (int)(Math.random() * radius);
    for (int step = 1; step <= length; step++) {
        BlockPos branchPos = BlockPos.containing(x + dir[0] * step, y + i, z + dir[1] * step);
        if (!world.isEmptyBlock(branchPos)) break;
        world.setBlock(branchPos, Blocks.SPRUCE_FENCE.defaultBlockState(), 3);
    }
}
for each of the 4 sides:
    65% chance to skip this side (no branch)
    pick a length from 1 to the radius
    for each step outward along that length:
        if the spot is not empty:
            stop this branch
        place a spruce fence

Each direction on each tier has a 65% chance of no branch, and a branch is from 1 to radius blocks long, stopping at the first occupied block. The spire is a loop from height - 2 to height + 1 placing spruce fences in empty positions, with a 40% chance of skipping each one for a broken look. It ends by calling FirTreeFinisher.finish.

FirSnagGenerationProcedure

The snag is a bare trunk and roots. Blocks near the top are randomly left out to simulate a snapped trunk, with a 30% skip chance for positions where i > height - 4, which is the top 3 blocks.

for (int i = 0; i < height; i++) {
    if (i > height - 4 && Math.random() < 0.3) continue;

    world.setBlock(BlockPos.containing(x, y + i, z), Blocks.SPRUCE_LOG.defaultBlockState(), 3);
}
for each level from 0 to height - 1:
    if this is one of the top 3 levels, 30% chance:
        skip it (leave a gap)
    place a spruce log here

FirTreeFinisher

The procedures place blocks one by one with default states. During world generation nothing updates them afterwards, so fences would never connect and every leaf would keep distance 7, making it decay. FirTreeFinisher.finish fixes the finished tree the way vanilla tree features do.

ConstantValueReason
RADIUS5Widest foliage tier is 4 blocks out, roots 1
HEIGHT31Tallest tree is 25 blocks plus a 4-block spire

It scans a box from base.offset(-5, -1, -5) to base.offset(5, 31, 5) in three stages:

  1. Every fence is updated with Block.updateFromNeighbourShapes, and every log (a state whose LeavesBlock.getOptionalDistanceAt is 0) is added to a queue at distance 0.
  2. A breadth-first search spreads from the logs through neighboring leaves in all six directions, recording each leaf's distance and stopping at LeavesBlock.DECAY_DISTANCE.
  3. Each leaf receives its computed distance. Leaves the sparse foliage cut off from the trunk are made persistent, like player-placed leaves.
Integer distance = distances.get(pos);
BlockState fixed = distance != null ? state.setValue(LeavesBlock.DISTANCE, distance) : state.setValue(LeavesBlock.PERSISTENT, true);
if (fixed != state)
	world.setBlock(pos, fixed, 2);
if a leaf distance was worked out for this position:
    set the leaves' distance to it
else:
    make the leaves persistent
if that changed the block:
    update it in the world
