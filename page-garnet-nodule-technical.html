Garnet Nodule [technical]

Overview

This page covers the code behind Garnet Nodule. The Garnet Nodule is the item strawberrymc:garnet_nodule, generated from the MCreator element GarnetNodule.mod.json. It is a separate item from the placeable Garnet blocks documented on Crystals [technical].

Registration

StrawberrymcModItems registers the item with a method reference to its class:

GARNET_NODULE = register("garnet_nodule", GarnetNoduleItem::new);
GARNET = register("garnet", GarnetItem::new);

public class GarnetNoduleItem extends Item {

The class adds no behavior, so the item uses default Item properties. Its sibling strawberrymc:garnet is written the same way in GarnetItem.
