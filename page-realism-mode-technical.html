Realism Mode [technical]

Two crafting materials from the early game of Realism Mode are coded as ordinary mod items: strawberrymc:flint_shard and strawberrymc:plant_fiber. Both are registered unconditionally and behave the same in every world.

Registration

The items are declared in the MCreator elements FlintShard.mod.json and PlantFiber.mod.json, and the generated StrawberrymcModItems registers each one against its own item class.

PLANT_FIBER = register("plant_fiber", PlantFiberItem::new);
FLINT_SHARD = register("flint_shard", FlintShardItem::new);
register the items: plant fiber, flint shard

The English names come from assets/strawberrymc/lang/en_us.json under item.strawberrymc.flint_shard ("Flint Shard") and item.strawberrymc.plant_fiber ("Plant Fiber"). Each item's client definition is a plain item/generated model under assets/strawberrymc/models/item.

Flint Shard

FlintShardItem extends Item and overrides one method. MCreator generates this override from the element's toolType value, so the shard mines every block at a speed multiplier of 1.2 instead of the default 1.0.

@Override
public float getDestroySpeed(ItemStack itemstack, BlockState state) {
	return 1.2f;
}
the tool always mines every block at speed 1.2

PlantFiberItem has a toolType of 1.0, which needs no override, so its class only forwards Item.Properties to the superclass.

Flint recipe

The element FlintRecipe.mod.json generates data/strawberrymc/recipe/flint_recipe.json, a shapeless crafting recipe that combines four shards into one vanilla flint.

{
  "type": "minecraft:crafting_shapeless",
  "category": "misc",
  "ingredients": [
    "strawberrymc:flint_shard",
    "strawberrymc:flint_shard",
    "strawberrymc:flint_shard",
    "strawberrymc:flint_shard"
  ],
  "result": {
    "id": "minecraft:flint",
    "count": 1
  }
}

Its recipe-book unlock is data/strawberrymc/advancement/recipes/flint_recipe.json, a child of minecraft:recipes/root. The advancement completes on either the minecraft:recipe_unlocked criterion for the recipe or a minecraft:inventory_changed criterion matching strawberrymc:flint_shard, and its reward is the strawberrymc:flint_recipe recipe.

Plant Fiber

Plant Fiber is the drop of the Palm Sapling. The PalmSapling.mod.json element sets customDrop to CUSTOM:PlantFiber with a dropAmount of 1, which MCreator writes out as the block's loot table, data/strawberrymc/loot_table/blocks/palm_sapling.json.

"pools": [
  {
    "rolls": 1.0,
    "conditions": [
      { "condition": "minecraft:survives_explosion" }
    ],
    "entries": [
      { "type": "minecraft:item", "name": "strawberrymc:plant_fiber" }
    ]
  }
