Echo Shrine

[UNRESOLVED] The source marks part of this topic as incomplete; review the notes before treating it as final.

The echo shrine is a structure that generates in the Voidstone Peaks biome and the Echoing Deep biome. This structure contains a Voidal Vault feature. The vault can be opened with a Depth Worm Key and contains various rare loot including:

Dechite Chunks [unresolved: more items]

Decayed Echo Shrine

This structure is the remains of a normal Echo Shrine destroyed by Endermen over the years. It provides basic materials needed to explore the Echoing Deep biome. Instead of normal Voidal Vaults, it contains Decayed Voidal Vaults with downgraded loot; these are opened with an Echo Shard instead of a Depth Worm Key. Decayed Voidal Vaults have a 1% chance to contain a Catalyst Lantern, which is needed to ward off the Wisp.
