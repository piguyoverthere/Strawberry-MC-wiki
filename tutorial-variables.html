Variables

Variables are the basic way in ComScript to store values to be modified or used later. In vanilla commands, scoreboards are typically used, but ComScript solves this problem with variables.

Variable names in ComScript are case sensitive.

An essential concept in ComScript variables are different data types, which dictate the type of the variable. Native ComScript data types  include:

  • String: Strings can be any character, including numbers, but these characters are "stale", meaning operations cannot be performed on them. Expected formatting: "<value>"
  • Binary (useful for raw files): Raw binary. Expected formatting: bin(<value>)
  • Boolean: A true, false, or null (placeholder) statement. Expected formatting: <true;> or <false;>
  • Float: Any number that can have decimal values. Expected formatting: <value>
  • Integer: Any non-decimal number. Expected formatting: <value>
  • Selector: Specific entity. Expected formatting: @e[type=pig]
  • CSON style: CSON components that dictate the styles of strings. Expected formatting: see Text styles

If you want to change/define the format of a variable or value, you can use the following anywhere a value goes, for example store new text = str(5);, which you will learn about later in this page.

Creation

Variables are created using store new <variable name> = <initial value>;. Multiple variables can be created with the same value using store new <variable name>, <variable name> = <init_value>;.

Legal variable characters include all uppercase and lowercase letters, common numbers, underscores, and dashes. If illegal characters are used, it either errors a syntax error for using periods/full stops or other syntax declaration characters, or errors: Unsupported token.

Static variables

Static variables are created using store new.static <variable name> = <initial variable value>. Static variables once created cannot be modified, which are called mutable variables (mut). Variables with no specified mutability are created default mutable unless specified in the header file.

Example:

store new.static doNotChangeThisVar = hello

If you attempt to change a static variable, then ComScript errors: Changed illegal static variable.

Replacing a variable

A variable's value and data type can be replaced in one step by using the following:

store set <variable name> = <value>;

Example:

store set cheese = "brie";

Modification

Existing variables are modified with the command store set <varname>=<float/int/bool/str_value>;. Variable values can be manipulated by using alter commands below. Note that once a variable is created, a conversion [see also: Input formatting] must be used to change the data set type, e.g., float, boolean, string... Spaces around the operators are optional.

Fetching

Variables can be called at any bracket depth as long as the input slot supports the type of variable you are calling, which you can convert to using the data type conversion syntax below. Variables are called by using the "$" symbol followed by the variable name, which is case sensitive.

Example:

store new cheese = "brie"
server.chat.out("The cheese is: ", $brie);
// Note the comma between the string and $brie conjoins the text together.

Convert data types

Convert to string

string(<value>)
str(<value>)

Convert to boolean

Only 1-digit binary integers, and strings with boolean names can be converted.

boolean(<value>)
bool(<value>)
booleanState(<int0-1>)

Convert to binary

Anything can be converted into binary, as it is the raw data type.

bin(<value>)
createBin(<value>)

Example:

store new bits = bin(0101011100110101);

Convert to float

float(<value>)
flt(<value>)

Convert to integer

integer(<value>)
int(<value>)

Value types and conversions

Values are integers, floats, strings, booleans, selectors (like @e[type=pig]) and text styles. Integers stay integers until a float is involved.

  • Strings can use "..." or '...'.
  • string()/str() turns any value into text. Floats are rounded to 10 decimal places, so sin(30) shows as 0.5.
  • boolean()/bool()/booleanState() accept only 0, 1, "true" and "false".
  • bin()/createBin() keeps a literal like bin(0101) as written. It turns integers into base 2 and text into the bits of its UTF-8 bytes.
  • integer()/int() drops the decimals of a float, reads a string of 0s and 1s (longer than one digit) as binary, reads other numeric strings as numbers, and turns booleans into 1 or 0.
  • float()/flt() reads numbers, numeric strings and booleans.

Boolean values

Boolean values conditions either true or false. Plain true and false values are written <true;> and <false;>. The semicolon inside them doesn't end the statement. Writing a bare true or false causes an error.

store new open = <false;>;
store set open = <true;>;
