Ocean Abyss [technical]

Overview

Ocean Abyss is the biome strawberrymc:ocean_abyss, the deepest, furthest-from-shore part of deep oceans and the only biome where ocean monuments generate. It is defined as datapack JSON and added to the overworld by a mixin. Its lowered sea floor comes from edits to the vanilla density functions.

Biome JSON

The biome is data/strawberrymc/worldgen/biome/ocean_abyss.json. It is added to the tags minecraft:is_ocean, minecraft:is_deep_ocean and minecraft:is_overworld.

Climate mixin

SurfaceBiomeDepthMixin injects at the return of StrawberrymcModBiomes.modifyOverworldParameterPoints. It adds the biome at the two depth points used for surface biomes, then gives it exclusive claim to its climate.

private static final Climate.Parameter[] OCEAN_ABYSS_CLIMATE = {
	Climate.Parameter.span(-0.45f, 1.0f), // temperature
	Climate.Parameter.span(-1.0f, 1.0f), // humidity
	Climate.Parameter.span(-1.05f, -0.7f), // continentalness
	Climate.Parameter.span(-1.0f, 1.0f), // erosion
	Climate.Parameter.span(-1.0f, 1.0f) // weirdness
};
ParameterRange
temperature-0.45 to 1 (every climate except frozen)
humidity-1 to 1

Vanilla already covers every climate value, so simply adding a biome would only tie with existing ones. For each biome in SURFACE_BIOMES, the mixin takes every climate box the biome owns and runs subtract against all other surface entries. subtract splits a box into the pieces outside the claimed box, dimension by dimension, and returns nothing if it lies entirely inside. isSurface limits the process to entries whose depth is the point 0 or 1, so cave biomes are left in place.

Terrain spline edits

The mod overrides data/minecraft/worldgen/density_function/overworld/offset.json and factor.json. Each file keeps the vanilla expression and adds one spline on minecraft:overworld/continents to it with a top-level minecraft:add.

Continents locationAdded to offsetAdded to factor
-1.100

-0.72-0.6825

All derivatives are 0. Inside the plateau from -1.06 to -0.72 the offset drops the whole floor and the large factor flattens it. The ramp from -0.72 to -0.68 straddles the biome's edge at continentalness -0.7, so the seabed falls away at the border of the biome.

Lava flood

Below y=-54 worldgen fills open space with lava instead of water, which would leave a layer of lava under the ocean, and lava springs can open into the water from the walls. AbyssLavaFlood is a feature that turns that lava into water. The configured and placed features are both named abyss_lava_flood, the placed feature has no placement modifiers so it runs once per chunk, and the biome modifier adds it in step top_layer_modification, after every other feature.

for (int x = minX; x < minX + 16; x++) {
	for (int z = minZ; z < minZ + 16; z++) {
		if (!level.getBiome(pos.set(x, BIOME_Y, z)).is(OCEAN_ABYSS))
			continue;
		for (int y = level.getMinY(); y < seaLevel; y++) {
			pos.set(x, y, z);
			if (level.getBlockState(pos).is(Blocks.LAVA)) {
				level.setBlock(pos, Blocks.WATER.defaultBlockState(), 2);
				changed = true;
			}
		}
	}
}

BIOME_Y is -54, so the biome is read near the floor. Every lava block from the bottom of the world to sea level in a matching column becomes water.

Ocean monument placement

data/minecraft/worldgen/structure/monument.json sets "biomes": "strawberrymc:ocean_abyss", step surface_structures, and a full-box monster spawn override of guardians, weight 1, group size 2 to 4. The axolotl and underground water creature overrides are empty lists.

Several mixins work together. The building's box is doubled by MonumentBuildingShellMixin using MonumentShell, giving a width of 116 blocks.

Lowering onto the floor

for (int i = 0; i <= 4; i++) {
	for (int j = 0; j <= 4; j++) {
		int x = box.minX() + (box.maxX() - box.minX()) * i / 4;
		int z = box.minZ() + (box.maxZ() - box.minZ()) * j / 4;
		int floor = context.chunkGenerator().getBaseHeight(x, z, Heightmap.Types.OCEAN_FLOOR_WG, context.heightAccessor(), context.randomState()) - 1;
		lowestFloor = Math.min(lowestFloor, floor);
	}
}
int dy = Math.max(lowestFloor, LOWEST_BASE_Y) - box.minY();
if (dy < 0)
	builder.offsetPiecesVertically(dy);

The heightmap is sampled on a 5 by 5 grid across the footprint and the lowest floor wins. LOWEST_BASE_Y is -58, which keeps a little deepslate over bedrock, as bedrock reaches up to y=-60. The monument only moves down. Pieces are rebuilt at their original height whenever a chunk loads from disk, so strawberrymc$keepSavedHeight moves the rebuilt pieces to the height of the saved box.

	continue;

For each column outside the footprint and within the radius, the basin floor is level with the monument's base for 8 blocks, then climbs 1 block per block of distance. Everything from the basin floor to sea level that is not already water becomes water. Air directly below the basin floor is flooded for up to 15 blocks, so caves the basin opens up do not leave air pockets. Where the dig exposed new stone, the top block becomes gravel, if it is in BASE_STONE_OVERWORLD and rests on something solid.
