Enchantments [technical]

Overview

This page covers the code behind Enchantments. The mod registers one data-driven enchantment, strawberrymc:electricution, displayed as "Shocking". It is generated from the MCreator element Electricution.mod.json into data/strawberrymc/enchantment/electricution.json. Its gameplay effect comes from EntityShockProcedure [raw], generated from EntityShock.mod.json.

The effect therefore applies to a damaged entity that is actively using an item with Shocking. Any level above 0 behaves the same, because the level value is only compared with 0.

Order of effects

  1. Sends ANGRY_VILLAGER, ENCHANTED_HIT and GUST particles, 2 of each, with spread 1 and speed 1.
  2. Applies the four armor damage checks below. Each check is independent, so more than one can apply on the same hit.
  3. Rolls Mth.nextInt(RandomSource.create(), 1, 8) == 1. On success, it runs the equipment drop.

Armor damage

Each check calls hurtServer with a new strawberrymc:shocking damage source. The slot read for each item is exact:

CheckItemSlot readDamage
LeggingsChainmail, golden, iron or copper leggingsLEGS2
BootsChainmail bootsFEET1
BootsGolden, iron or copper bootsLEGS1
HelmetChainmail helmetFEET1
HelmetGolden, iron or copper helmetLEGS1
ChestplateChainmail chestplateFEET3
ChestplateGolden, iron or copper chestplateLEGS3

With equipment in its normal slots, only the leggings row and the chainmail boots row match, because the other rows look for a piece in a slot that does not normally hold it.

Equipment drop

On the 1 in 8 roll, the procedure picks Mth.nextInt(RandomSource.create(), 100, 103) as a slot index and reads that index through the entity's Capabilities.Item.ENTITY handler. It spawns the stack as an ItemEntity with a pickup delay of 5 at the entity's position, empties the slot, and plays item.shield.break with SoundSource.NEUTRAL.

shockSlotDrop = Mth.nextInt(RandomSource.create(), 100, 103);

}
