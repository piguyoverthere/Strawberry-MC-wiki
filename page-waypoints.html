Waypoints

Overworld Waypoints

Waypoints are structures that generate in the Overworld. They are divided into Continental and Local Waypoints and allow faster travel over long distances. Travel requires a potion. Waypoints have a 2% chance to malfunction and teleport the player to a random waypoint they have already discovered.

Local Waypoints

Generation and Functions

With an Uncrafting Potion, players can teleport to surrounding Local Waypoints on the same continent within 1,500 blocks. This uses the same logic as Voidal Waypoints, except that the direction the player is facing is used instead of a projectile.

Local Waypoints generate near significant landmarks, including:

  • Inhabited Snowy Glades
  • Villages
  • Abandoned Villages
  • Woodland Mansions
  • Pillager Outposts
  • Desert Temples
  • Ocean Monuments
  • Sometimes above Trial Chambers
  • Strongholds
  • Covens

Significant Underground Features

Chiseled Cauldrons can be found inside Waypoints. See Chiseled Cauldrons for their creation and functionality.

Man-Made Waypoints

Players can create Waypoints using special materials to craft a Core of Teleportation. When placed, the Core checks whether the current coordinates are suitable for a Chiseled Cauldron. If they are, it turns into a Chiseled Cauldron and a Waypoint.

Voidal Waypoints

Voidal Waypoints are small, room-like underground variants that generate in the End. They contain End Anchors and Casting Cauldrons. Endillary plants generate above them, and Voidal Waypoints typically generate adjacent to Ender Relays.

Related Voidal features

  • Ender Relays
  • Casting Cauldrons
  • Palline Refinery
