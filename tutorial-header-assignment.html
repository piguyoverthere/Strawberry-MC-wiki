Header Assignment

Header files in ComScript are similar to .h files in C++, that define the global properties of a ComScript file. It is good practice to assign each comscript file with a header, but it will not cause any errors and will run fine (most of the time) if you don't assign a header.

Headers can be included with the following syntax: [this would be the very start of a ComScript file]

#properties("my-header.h.md");

All header conditions should have a .property.world(client.level); property to execute within the level the client has open (this level), or .property.world(server.level); for multiplayer worlds to let your scripts apply to everyone.

Header files are structured with a heading at the start defined by "#", body properties, and a ending condition:

//this is a header file
#header;
*conditions.header(){
    .property.global:executeAs($target);
    .property.global:executeAt(0, 0, 0);
    .property.oplevel(4)
    .property.world(client.level);
}
