Ancient Sand

Ancient Sand is a block native to desert temples affected by gravity. Unlike other blocks, ancient Sand does not trigger the calibrated sensors embedded within the structure of the desert temple, allowing them to be placed and broken within the perimeter of the sensors. This means that Ancient Sand blocks can be used to interact saftely with the puzzles in the Desert Temple. Each block of ancient Sand contain a non-modifiable attribute containing the id of the desert temple it generated in, as these blocks dissapear after the mancer of the temple is defeated. This is to prevent ancient Sand from being smuggled across temples to be used to cheat certain puzzles.
