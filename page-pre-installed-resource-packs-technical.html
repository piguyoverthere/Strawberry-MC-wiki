Pre-Installed Resource Packs [technical]

The mod ships four packs inside its jar and registers each one as a built-in, always-active pack through NeoForge. Two carry client assets and two carry server data. See the main page, Pre-Installed Resource Packs.

Registration

Each pack is a folder under src/main/resources with its own pack.mcmeta. A static method subscribes to AddPackFindersEvent on the mod event bus and calls addPackFinders. The identifier's path names the folder, so strawberrymc:comscript points at src/main/resources/comscript.

private static void addPack(AddPackFindersEvent event) {
	event.addPackFinders(Identifier.fromNamespaceAndPath("strawberrymc", "comscript"), PackType.CLIENT_RESOURCES, Component.literal("Strawberry MC ComScript"),
		PackSource.BUILT_IN, true, Pack.Position.TOP);
}

Every registration passes the same trailing arguments:

  • PackSource.BUILT_IN marks the pack as supplied by the game rather than by the player.
  • true makes the pack always active.
  • Pack.Position.TOP places it at the top of the pack list, so its files take precedence over the packs below it, including the mod's own data.

The registering classes are initialized from the user-code block of the StrawberrymcMod constructor, each receiving the mod event bus.

ComScript client pack

The comscript pack holds the client side of the Scripter block. Its description is "Strawberry MC ComScript (Scripter block and editor font)".

  • assets/strawberrymc/lang/en_us.json, the Scripter's text.
  • blockstates/scripter.json, models/block/scripter.json, items/scripter.json and textures/block/scripter.png, the block's visuals.
  • font/jetbrains_mono.json, font/jetbrains_mono_regular.ttf and font/JetBrainsMono-OFL.txt, the editor font and its license.

Its use is described in Scripter [technical].

Monument cutscene client pack

The monument_cutscene pack holds the chime sound and the two particle definitions used by the Ocean Monument cutscene. Its description reads "Strawberry MC monument cutscene chime (kept out of MCreator's generated sounds.json)".

  • assets/strawberrymc/sounds.json and sounds/monument_chime.ogg.
  • particles/rune_funnel.json and particles/sensor_glyph.json.

Its use is described in Ocean Monument [technical].

Built-in data packs

void_terrain and monument_puzzles use the same mechanism for PackType.SERVER_DATA. Comments on both classes give the reason for the separate packs: MCreator regenerates the mod's own data folder, so these files live where it cannot overwrite them. void_terrain also relies on its position at the top of the pack list, because its dimension/void_dim.json replaces the copy MCreator generates from the VoidDim element. tools/void_terrain/gen.py and tools/monument_puzzles/gen.py write those packs' files. They are covered further in The Void [technical] and P2 Piston Puzzle [technical].
