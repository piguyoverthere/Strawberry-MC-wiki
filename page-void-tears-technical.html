VoidTearsFluid

VoidTearsFluid extends BaseFlowingFluid. A shared PROPERTIES object links the type, both fluids and the liquid block, with an explosion resistance of 100 and a tick rate of 4. Drips use the SQUID_INK particle.

public static final BaseFlowingFluid.Properties PROPERTIES = new BaseFlowingFluid.Properties(() -> StrawberrymcModFluidTypes.VOID_TEARS_TYPE.get(), () -> StrawberrymcModFluids.VOID_TEARS.get(),
		() -> StrawberrymcModFluids.FLOWING_VOID_TEARS.get()).explosionResistance(100f).tickRate(4).block(() -> (LiquidBlock) StrawberrymcModBlocks.VOID_TEARS.get());

@Override
public boolean move(LivingEntity entity, Vec3 movementVector, double gravity) {

	return true;
}

Procedures

Damage

VoidTearsDamageApplyProcedure [raw] runs whenever an entity is inside the block. It uses StrawberrymcMod.queueServerWork to wait 20 ticks and then deals 5 damage of the custom type strawberrymc:void_tear_damage.

StrawberrymcMod.queueServerWork(20, () -> {
	{
		Entity _ent = entity;
		if (_ent.level() instanceof ServerLevel _serverLevel) {
			_ent.hurtServer(_serverLevel, new DamageSource(world.holderOrThrow(ResourceKey.create(Registries.DAMAGE_TYPE, Identifier.parse("strawberrymc:void_tear_damage")))), 5);
		}
	}
});

Hiss

VoidTearHissProcedure [raw] runs when a neighboring block changes. It plays block.lava.extinguish in the ambient sound category at volume 1 and pitch 1, at the fluid block's position. On the server it uses playSound, and on the client it uses playLocalSound.

Client rendering

VoidTearsFluidExtension registers the fluid model and the client fluid type extension. While the camera is in the fluid, the overlay texture is strawberrymc:textures/void_tears_overlay.png, the fog color is set to red 0, green 0, blue 0.0667, and the fog runs from distance 0 to the smaller of 48 and the render distance.

fluidFogColor.set(0f, 0f, 0.0666666667f, fluidFogColor.w);

fogData.environmentalStart = 0f;
fogData.environmentalEnd = Math.min(48f, renderDistance);

Pool feature

Pools are placed in The Void by three files in the void_terrain datapack:

FileContent
configured_feature/void_tears_pool.jsonminecraft:lake, fluid strawberrymc:void_tears level 0, barrier strawberrymc:voidstone
placed_feature/void_tears_pool.jsonrarity_filter chance 6, in_square, heightmap WORLD_SURFACE_WG, biome
neoforge/biome_modifier/void_tears_pools.jsonAdds the feature in step lakes to abyssal_plains, echoing_deep and voidstone_peaks

A chunk has a 1 in 6 chance of attempting one pool, at the top surface of a random column. The heightmap finds the topmost non-air block in the column, so a pool can form on the plain or on top of an island. The fluid is also the dimension's default_fluid, but with sea_level at -64 and aquifers disabled, pools are where it appears in the terrain. Pools are lined with Voidstone.
