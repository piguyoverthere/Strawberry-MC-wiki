Prismatic Sensor

The Prismatic Sensor is a special block responsible for detecting block broken in the Ocean Monument and replacing them to prevent greifing before the puzzles and boss are completed. If a block is broken, one of the four Prismatic Sensors located in the 4 quadrants of the Ocean Monument will activate, causing the block to not drop and be replaced while spawning enchantment table particles (server side).


Active

Active Prismatic Sensors have a deep blue matrix with 2 panels of red breathing illuminators on each side, depicting its state. Client-side enchantment table particles are expelled from the sides that orbit the main block. Particles are culled if >30 particles are detected in a chunk.


Deactivated[see also: Water Dragon]

Deactivated Prismatic Sensors have the same deep blue matrix as the active sensors but have light blue breathing panels instead of red ones. These deactivated sensors allow block to be broken and are only deactivated after the Water Dragon is beaten.
