Remixing the mod

For non-commercial remixes, credit must be placed in an obvious location. Commercial distribution of remixes is prohibited. Read the terms and conditions for more details; remixes are subject to the same terms.

To customize the mod, install MCreator. Avoid fake download buttons, and select the 2026.2 version compatible with the mod.

While the apps are installing, install Git for Windows.

Create a GitHub account if you do not already have one. The source identifies the mod repository as Uncraftable-strawberry-pickax (without the final “e”) and says to use the repository owned by i-am-also-coder-314159, not the similarly named repository owned by i-am-a-coder-314159.

Make a folder for the remix, open it in VS Code, and open a new terminal from the Terminal menu. Clone the repository by running:

git clone <repo URL>

The repository files should appear in the folder after cloning.

Committing changes

If there are no staged changes, first stage them with:

git add .

After staging changes, merge the checkout into main with git merge main, or use git commit to keep the changes on a separate branch.

GitMC version tracking

GitMC is a native Git-like version tracker that tracks changes in a specified world using a Git chart diagram, as seen in Git Bash. It makes it easier to track and modify changes in a world when collaborating or building solo. GitMC interfaces can be accessed through the GitMC button in the Esc menu.

Attributes

GitMC attributes have shorthand codes listed below the relevant commands. An attribute is valid only for the commands that list its code.

A1: --f

Forces the given command before overriding all warnings.

A2: --abort

When using the built-in merge conflict resolver, use this attribute to cancel the merge and revert to the last unconflicting commit on the current branch:

git merge --abort

This automatically reverts to the last change on the native branch, so no pull request is needed.

A3: --squash (computationally expensive)

Git merge squash can make the two instances (main/origin) overwrite all air blocks within the branch. This method is extremely unstable because block states stored natively on the other instance are not transferred, which can lead to fatal errors.

Example:

git merge eric_branch --squash

A4: --clear

Clears all data in the provided text column.

Syntax

:wq

Write and quit is used to close a native text box opened by Git.

Syntax:

:wq

Commit

Committing changes to the Git graph requires a commit message.

Example:

git commit

If no -m attribute is given in the console, GitMC generates a temporary .gitignore text file where the commit message can be typed and closed.

Valid attributes: A1, A2 (only during a transaction).

Pull

Git pull fetches changes that others may have made to the global repository. It cannot be used when the branch is too many commits ahead of or behind main, or while still in the Git merge menu.

Example:

git pull

Push

After changes are committed, Git push can add them to main in a solo world. If conflicts are detected between branches, choose to keep the incoming changes, keep the current branch's changes, or attempt to merge them. If a conflict is too complex to merge, resolve it manually in VS Code or revert to a previous unconflicting commit.

Example:

git push main

Valid attributes: A1, A2 (only during a transaction).

Log

Git log provides a chronological list of all commits in the specified branch.

Example:

git log

Valid attributes: A2 (only during a transaction), A4.

Reload

Git reload pulls local changes and updates them into the world. If the process takes too long, use A2.

Example:

git reload <opt: instance name>

Merge

Git merge in GitMC combines two instances of a world with changes you want to keep, without overwriting one with the other. The changes are combined into a single automatic commit.

Example:

git merge <branch name>

If someone changes the main branch after you check out your branch, conflicts may occur. GitMC should usually resolve them automatically. For worlds with changes larger than 5 MB, Git merge cannot automatically merge; accept all current or incoming changes (overwriting the other instance), or merge them manually in VS Code or the built-in GitMC conflict resolver.

Valid attributes: A1, A2, A3.

Revert

To revert a world to a previous version of its save data, use:

git revert <commit name/message>

When working on a world with multiple contributors, create a pull request (PR) that the other contributors must approve. The revert occurs after approval, which is reported in the GitMC UI. To view the delta log for debugging, use:

git revert --delta-log

Valid attributes: A1, A2 (only during a pull request).

Build

Git build emulates the code to check for corrupted values, undefined variables, and other errors that could crash the computer if the code were run immediately. The source text ends before completing its explanation of the build result.

Syntax:

git build
