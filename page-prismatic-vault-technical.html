Prismatic Vault [technical]

Overview

The Prismatic Vault sits at the center of a glass-topped water tank on the roof of the Ocean Monument. Using a Monument Key on it plays a cutscene in which rune glyphs funnel down to the Prismatic Rune at the bottom of the tank, and the rune then rises to just under the glass. MonumentShell.buildArena builds the tank at world generation, monument/MonumentArena.java runs the server sequence, and monument/client/ArenaCutscene.java runs the camera.

Layers

buildArena loops over a square of radius 15 around the center, skips columns further than 15.2 away, and treats columns further than 14.2 as wall. Each column writes depth 0 to depth 9 below the vault's y.

if (depth == 0)

else if (depth == Layout.TANK_DEPTH + 2)
	state = Blocks.PRISMARINE_BRICKS.defaultBlockState();
else if (wall)
	state = depth == 4 && (dx * 7 + dz * 3) % 5 == 0 ? Blocks.SEA_LANTERN.defaultBlockState() : Blocks.PRISMARINE_BRICKS.defaultBlockState();
else if (depth == Layout.TANK_DEPTH + 1)
	state = random.nextFloat() < 0.3F ? Blocks.GRAVEL.defaultBlockState() : Blocks.SAND.defaultBlockState();
else
	state = Blocks.WATER.defaultBlockState();

The random source for each column is seeded from its X and Z, so a column gets the same result regardless of chunk generation order. Below the wall, water is replaced with bricks from depth 10 down, stopping at the first non-water block or at depth 26, so the wall stays propped up where the roof falls away.

Rune frame and fish

After the column loop, the vault goes at the center and a minecraft:dark_prismarine pedestal goes at 7 below it. If the frame's position is in the chunk being generated, spawnArenaEntities runs, so the entities are created exactly once.

net.minecraft.world.entity.decoration.ItemFrame frame = new net.minecraft.world.entity.decoration.ItemFrame(serverLevel, layout.runeFrame(), Direction.UP);
frame.setItem(new net.minecraft.world.item.ItemStack(io.github.strawberrymc.init.StrawberrymcModItems.PRISMATIC_RUNE.get()), false);
((io.github.strawberrymc.custommixin.ItemFrameAccessor) frame).strawberrymc$setFixed(true);
frame.setInvulnerable(true);
frame.addTag(MonumentArena.RUNE_FRAME_TAG);
level.addFreshEntity(frame);

ItemFrameAccessor exposes the frame's private fixed field. The tag is strawberrymc.rune_frame. MonumentArena also cancels PlayerInteractEvent.EntityInteract and AttackEntityEvent on a tagged frame for any player not in creative mode.

Nine fish are spawned with a random source seeded from the arena's center: 6 minecraft:tropical_fish and 3 minecraft:cod. Each is placed 2 to 12 blocks from the center at a random angle, 2 to 6 blocks below the glass, using EntitySpawnReason.STRUCTURE. All are marked as persistent.

Using the vault

MonumentArena.onUseBlock listens to PlayerInteractEvent.RightClickBlock on the server. The checks run in this order:

  1. If the block is not a Prismatic Vault, it returns. Otherwise the event is cancelled with InteractionResult.SUCCESS, whatever is in the player's hand.
  2. If the vault is not the one at the arenaCenter of the monument at its position, it returns silently.
  3. If the rune frame is missing or empty, or this vault is in the OPENING set, the action bar shows "The vault is already open".
  4. If the held item in the hand used is not a Monument Key, the action bar shows "The vault needs a Monument Key".
  5. Outside creative mode, the stack shrinks by 1, and open runs.

Funnel particle

Each glyph starts in a ring around the vault, at radius 1.2 to 2.8 and 1.2 to 2.2 above it. The server sends it with count 0, so the three offset arguments arrive at the client as the particle's velocity. The particle uses them as its destination, the frame's center lowered by 0.35.

level.sendParticles(RUNE_FUNNEL.get(), true, true, x, vault.getY() + 1.2 + level.getRandom().nextDouble(), z, 0, target.x, target.y, target.z, 1.0);

QuestHud.RuneFunnel registers the sprites from rune_funnel.json, the same 26 minecraft:sga_* glyph sprites as the sensor glyph. Lifetime is 40 to 54 ticks, size 0.12 to 0.18, block light 15, with no physics. Its position is computed from p = age / lifetime.

float p = (float) age / lifetime;
double r = radius * (1 - p * p * (3 - 2 * p));
double angle = startAngle + p * Math.PI * 2.5;
x = targetX + Math.cos(angle) * r;
z = targetZ + Math.sin(angle) * r;
y = Mth.lerp(Math.pow(p, 1.4), startY, targetY);
this.rCol = 0.2F + 0.6F * p;
this.gCol = 0.55F + 0.4F * p;
setAlpha(Math.min(1, Math.min(p / 0.15F, (1 - p) / 0.1F)));

Blue stays at 1.0, so the color moves from (0.2, 0.55, 1.0) to (0.8, 0.95, 1.0) as the glyph descends. The type is registered with new SimpleParticleType(true).

The floating rune

MonumentArena.release does nothing if the frame is missing or empty. Otherwise it copies the frame's stack, clears the frame and its glowing tag, and spawns an ItemEntity at the frame's center.

floating.setNoGravity(true);
floating.setNeverPickUp();
floating.setUnlimitedLifetime();
floating.setGlowingTag(true);
floating.addTag(RISING_RUNE_TAG);

The tag is strawberrymc.rising_rune. For each tick t from 1 to 90, the server queues a position of start.y + (topY - start.y) * ease(t / 90), where topY is the vault's y minus 0.6 and ease is smoothstep. After the final tick the rune stays floating just under the glass, and the vault answers with "The vault is already open".

Camera

ArenaCutscene.start ignores the packet if the entrance or vent cutscene is playing. The frame position is the bottom center of the frame's block, and the surface is the vault's y minus 0.6. The camera's starting angle is the direction from the frame to the player, so the view comes from the side the player is standing on. Before tick 30 and from tick 218, currentShot returns null and the camera stays on the player.

double angle = startAngle + Math.toRadians(40) * (time - CUT_IN) / (CUT_OUT - CUT_IN);
Vec3 desired = new Vec3(frame.x + Math.cos(angle) * DISTANCE, frame.y + 1.0 + rise * 0.6, frame.z + Math.sin(angle) * DISTANCE);
// Keep a clear line of sight from just above the frame
Vec3 anchor = new Vec3(frame.x, desired.y, frame.z).add(0, 0.5, 0);

The packet is strawberrymc:arena_cutscene, registrar version 1, carrying the frame and vault positions. Its handler runs only on the client, so the client-only cutscene class is never loaded on a dedicated server. CutsceneCameraMixin gives this cutscene priority over the other two when applying the shot, and protection comes from MonumentIntro.protect, described on Ocean Monument.

Reset

/cutscene clear calls PrismaticSensors.resetVent, which calls MonumentArena.reset for a player inside a monument. The reset removes the vault from OPENING, discards every item tagged strawberrymc.rising_rune within 14 blocks horizontally and 12 vertically of the vault, puts a new Prismatic Rune in the frame, and clears the frame's glowing tag.
